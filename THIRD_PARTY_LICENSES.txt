-----------------------

Runtime-downloaded PalDefender
------------------------------
- PalDefender, copyright Ultimeit: MIT. The complete license is included as
  licenses/PalDefender-MIT.txt.
- PalPanel does not bundle PalDefender binaries. During an explicitly requested
  install or update, it downloads d3d9.dll and PalDefender.dll from the latest
  stable official GitHub Release and verifies the published SHA-256 digests.
  A digest-verified PalDefender.zip is used only when the direct DLL assets are
  not present in that Release.

MapLibre map renderer
----------------------
- MapLibre GL JS 5.24.0: BSD-3-Clause. Release builds synchronize the exact
  browser UMD bundle, CSS and LICENSE.txt from the pinned npm version and serve
  them from PalPanel itself; browsers do not use a CDN. The v5 runtime supports
  WebGL2 and WebGL1 instead of requiring WebGL2-only initialization.
- The synchronized license is embedded at
  `/vendor/maplibre-gl/LICENSE.txt` in the web UI release assets.

PalPanel world map assets and PalOps implementation reference

- ninhua/palpanel-assets: dedicated map-resource repository used by release builds.

  from that repository remain authoritative.
- CoderYiXin/PalOpsWeb 1.3.2, commit
  dc2ec173c77e759482e59d9b63d228c88132061c: GPL-3.0-or-later. PalPanel

- Palworld, its map imagery, names, and artwork remain property of Pocketpair,
  Inc. They are not relicensed under PalPanel's GPL.

The release SBOM provides the exact package/version inventory. Corresponding
license texts remain available from each dependency's source distribution and
are preserved in the sav-cli vendored source archive where required by GPL.

Mirrored dependency snapshots
-----------------------------
PalPanel can build from a separately stored vendor mirror. Every mirrored source
or asset must retain its original license, copyright notices, provenance, pinned
revision, and generated SHA-256 manifest. The mirror tooling itself does not
grant redistribution rights. Private credentials and authorization documents
containing personal information must not be included in public source archives.
