# 0.8.73

本版集中优化诊断控制台的请求头编辑、历史记录和自定义模板。

## 请求头 JSON 双视图

- 左侧保留原始 JSON 编辑区。
- 右侧提供结构化对象编辑器。
- 点击“＋”添加常见或自定义请求头。
- 点击“－”删除对应字段。
- 支持格式化、压缩和解析 JSON。
- 两侧解析后同步，仍按标准 JSON 对象发送。

## Authorization 自动识别

- 新增 `Authorization` 时默认使用 `Bearer`。
- 只填写 Token 即可，发送时自动补齐 `Bearer `。
- 粘贴 `Bearer token` 或 `Basic value` 时自动识别认证方案并拆分前缀。
- 不会生成 `Bearer Bearer token` 一类重复前缀。
- 仍可切换为 `Basic` 或“自定义”原始值。

## 自定义诊断模板

- 当前 HTTP 请求或终端命令可以保存为浏览器自定义模板。
- 同名模板会被最新内容替换。
- 最多保存 20 个自定义模板。
- 可重新载入和删除自定义模板。
- 模板包含完整 URL、请求头、请求体或终端命令。

## 历史记录去重

- 相同 HTTP 请求只保留最新一次响应。
- 相同终端命令只保留最新一次执行结果。
- 去重依据为请求类型和完整请求内容，不再因为响应耗时不同产生重复记录。
- 历史上限仍为 30 条。

## 本地数据保存策略

按照管理端使用需求，诊断历史和自定义模板不再隐藏 `Authorization`、Cookie、Token、密码字段或请求体内容。数据原样保存在当前浏览器的 `localStorage` 中，不发送到额外服务。

此行为便于重复诊断，但意味着浏览器本地存储中可能存在凭据。请仅在受信任设备和受控管理会话中使用诊断控制台，并在不再需要时清空历史或删除模板。

## API 与版本

- 没有新增或删除后端接口。
- OpenAPI 操作数量保持 338。
- 运行时补丁信息、OpenAPI 和生成的 TypeScript 合约同步到 `0.8.73`。
