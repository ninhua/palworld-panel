# 0.8.86-boss-registration1

本增量建立 Boss 活动报名、人数上限和区域资格的后端闭环。

## 功能

- 每个召唤记录独立配置报名开关、人数上限、活动半径、是否计算 Z 轴，以及活动开始后是否继续允许报名。
- PlayerUID 使用统一规范化和 SQLite `PALPLAYERUID` 排序规则，格式变体不会重复占位。
- 报名、重复报名、区域核验、取消报名均为事务操作；每个召唤使用带过期时间的数据库租约串行修改，多进程下人数上限不会被并发穿透。
- 区域核验默认使用 X/Y 水平距离，可显式启用 Z 轴距离。
- 没有配置活动半径时，报名者直接视为符合区域资格；配置半径后，没有位置快照的报名者保持 `unknown`，在区域内为 `eligible`，区域外为 `outside`。
- 取消报名会释放人数名额；重复取消和重复报名保持幂等。
- 新增 `boss_summon_participants` 与 `boss_participant_events`，保存参与者状态和完整审计。

## API

不新增路由。继续使用：

```http
POST /api/boss/summons/{summon_id}/transition
```

### 配置报名

```json
{
  "status": "registration_configure",
  "result": {
    "enabled": true,
    "max_players": 20,
    "radius": 5000,
    "use_z": false,
    "allow_active": false
  }
}
```

### 玩家报名

```json
{
  "status": "participant_register",
  "result": {
    "player_uid": "00112233445566778899AABBCCDDEEFF",
    "nickname": "Player",
    "steam_id": "steam_76561198000000000",
    "location": {"x": 100, "y": 200, "z": 300}
  }
}
```

`location` 可省略。配置了区域半径但没有位置时，玩家先进入报名列表，区域状态为 `unknown`。

### 核验区域

```json
{
  "status": "participant_check_area",
  "result": {
    "player_uid": "00112233445566778899AABBCCDDEEFF",
    "location": {"x": 100, "y": 200, "z": 300}
  }
}
```

### 取消报名

```json
{
  "status": "participant_cancel",
  "result": {
    "player_uid": "00112233445566778899AABBCCDDEEFF",
    "reason": "玩家主动退出"
  }
}
```

### 查询快照

```json
{
  "status": "registration_snapshot",
  "result": {"include_cancelled": false}
}
```

响应包含报名策略、已报名人数、签到人数、区域外人数、剩余名额、参与者列表和最近 200 条参与者审计事件。

## 边界

本增量不自动读取 PalPanelBridge 在线玩家坐标，也不提供游戏聊天报名命令。当前位置由调用方传入；下一增量再接入在线玩家位置查询、游戏内报名和面板操作界面。
