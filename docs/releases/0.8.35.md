# PalPanel 自定义版 0.8.35

发布日期：2026-07-29

## 技术预览

- 新增只读 `PalPanelBridge` UE4SS C++ 探针，验证 localhost HTTP 请求能够进入 UE4SS `on_update` 游戏线程回调。
- 探针只允许 `127.0.0.1`、强制 Bearer Token、限制任务队列，不提供任意 UObject 调用或游戏数据修改。
- 恢复 `PalPanelBridge build` 云端构建工作流；通过仓库 Secret `UEPSEUDO_TOKEN` 以已绑定 Epic Games 的 GitHub 账号只读拉取 UEPseudo，不把凭据写入源码或构建产物。
- 云端构建安装 Rust 工具链，并向 UE4SS Corrosion 显式传递 `rustc` 路径，避免 Windows Runner 无法自动发现编译器。
- 桥接目标作为子目录注入 UE4SS 根 CMake 工程，沿用官方顶层构建配置，避免把 UE4SS 当依赖子目录时 linker flags 被误解析。
- 构建期间将 UE4SS v3.0.1 的 Corrosion 临时固定到官方 `/defaultlib:msvcrt` 修复提交，兼容当前 Rust MSVC 工具链；构建后恢复 SDK 文件。
- 构建期间临时应用 UEPseudo 当前主线已采用的 `unordered_map::find` 单行兼容修复，使固定的 v3.0.1 SDK 能通过 MSVC 14.44；构建后恢复 SDK 文件。
- 构建期间临时补入 UEPseudo 主线的 `EAspectRatioAxisConstraint` 声明，修复固定 v3.0.1 头文件在当前 MSVC 下的缺失类型错误。
- 将 UE4SS v3.0.1 浮动的 ImGuiColorTextEdit `master` 固定到其发布时兼容提交，避免新 TextEditor API 与固定 ImGui v1.89 不匹配。
- 保留本地构建脚本作为可选备用方式。
- 云端构建产物改为独立的 `PalPanelBridge-v0.1.0-ue4ss-v3.0.1.zip` 服务端模组包；解压后可直接将 `PalPanelBridge` 文件夹放入 UE4SS `Mods` 目录。
- 模组包内置 `enabled.txt`，无需覆盖服务器已有的 `mods.txt`；同时提供待配置的 `config.ini`、DLL 校验值和许可证。
- `PalPanelBridge 0.1.1` 不再于 `start_mod` 构造阶段读取配置或启动 HTTP 线程，改为等待 `on_unreal_init` 后初始化，避免阻塞 PalServer 启动。

## 验证重点

- GitHub Actions 必须按照 UE4SS 官方方式使用 MSVC、Ninja、固定的 UE4SS v3.0.1 SDK 和 `Game__Shipping__Win64` 配置成功构建探针 DLL，并生成 SHA-256 校验文件。
- Action 必须校验压缩包内存在 `PalPanelBridge/dlls/main.dll`、`config.ini`、`enabled.txt` 和 `SHA256SUMS`。
- 探针任务应从 `queued` 进入 `completed`，并返回游戏线程 tick 和 Unreal 初始化状态。
- 未配置 Token、非回环监听和未知接口必须被拒绝。

完整比较：`v1.3.0-custom.0.8.34...v1.3.0-custom.0.8.35`
