# PalPanel 自定义版 0.8.43

发布日期：2026-07-30

## 新增功能

- 世界地图瓦片、固定 POI、图标、元数据和许可证统一接入 `ninhua/palpanel-assets` 专用资源仓库。
- Linux 与 Windows 打包流程会将资源仓库 ref 解析为不可变提交 SHA，再下载、验证并嵌入完整地图资源。
- 支持公开资源仓库，以及通过 `PALPANEL_MAP_ASSETS_TOKEN` 读取私有资源仓库。
- 支持使用本地资源目录或预下载 ZIP 完成离线构建。

## 资源完整性

- 三语言 POI 数据必须具有相同的 ID、图层、类别和坐标。
- `palpagos` 和 `world-tree` 必须各自包含完整 0–4 级 WebP 瓦片金字塔，共 341 个瓦片。
- 若资源仓库提供文件清单，构建会校验文件大小与 SHA-256。
- 打包后的运行时清单记录资源仓库、提交、ref、资源/数据集版本、POI 数量、瓦片计数和全部文件哈希。

## 前端行为

- 地图清单不再固定要求旧 `CoderYiXin/PalOpsWeb` 提交，改为验证 `ninhua/palpanel-assets` 及构建时解析的非空提交信息。
- POI 数量由运行时清单驱动，避免资源仓库更新数据后前端仍硬编码旧数量。
- 探索记录切换到新的 `palpanel-assets-v1` 本地命名空间，避免与旧 PalOps 数据集记录混用。
- 地图来源面板显示实际资源仓库、提交、资源版本和数据集版本。

## 构建与配置

新增环境变量：

- `PALPANEL_MAP_ASSETS_REPOSITORY`：默认 `ninhua/palpanel-assets`。
- `PALPANEL_MAP_ASSETS_REF`：默认 `main`。
- `PALPANEL_MAP_ASSETS_TOKEN`：私有仓库只读 Token。
- `PALPANEL_MAP_ASSETS_SOURCE_DIR`：本地资源仓库目录。
- `PALPANEL_MAP_ASSETS_ARCHIVE`：本地资源 ZIP。
- `PALPANEL_MAP_ASSETS_TILE_SOURCE_DIR`：可选独立瓦片目录。
- `PALPANEL_ALLOW_MISSING_MAP_TILES`：仅用于开发诊断，正式发布不应启用。

旧 `PALPANEL_PALOPS_*` 本地路径变量暂时保留为兼容别名。

## 版本与接口

- 后端补丁版本由 `0.8.42` 更新为 `0.8.43`。
- OpenAPI `PatchInfo.patch.version` 常量及前端生成契约同步为 `0.8.43`。
- 未修改数据库结构或公开 API 路径。

## 升级注意事项

- 地图资源仓库必须符合 `docs/palops-map-migration.md` 中的目录和完整性约定。
- 若资源仓库为私有仓库，需在面板仓库配置 `PALPANEL_MAP_ASSETS_TOKEN` Actions Secret。
- 必须重新构建并部署完整包；旧包不会自动下载新增瓦片。
- 部署后强制刷新世界地图页面，清除旧前端分块缓存。

## 验证范围

- 地图资源同步器单元测试：完整瓦片、本地目录与单根 ZIP、POI 本地化一致性、缺失瓦片、源清单哈希漂移、Git LFS 指针和显式无瓦片模式。
- Linux Shell 与 Windows PowerShell 打包参数接入。
- GitHub Actions YAML、前端 TypeScript 语法、Shell/Python 校验；完整 Lint、前端测试与跨平台发布包构建由 CI 执行。
