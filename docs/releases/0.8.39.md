# PalPanel 自定义版 0.8.39

发布日期：2026-07-29

## 世界地图迁移

- 使用 PalOps Web 1.3.2 的 Palpagos / World Tree 双地图数据模型替换旧版单图 SVG 地图。
- 使用固定、自托管的 MapLibre GL JS 6.0.0 渲染离线瓦片和 GeoJSON 标记，不从浏览器访问 CDN。
- 新增 30 类固定 POI 的分组显示、搜索、探索记录和未发现筛选。
- 玩家、据点、帕鲁和地图对象继续使用 PalPanel 实时与存档索引 API。
- 玩家位置刷新间隔支持 1、2、3、5、10、15 或 30 秒。
- 新增 PalOps 固定提交资源同步和 MapLibre 固定版本完整性校验脚本。

## 地图瓦片许可边界

- PalOps 当前元数据把引用的栅格瓦片标记为不可再分发，因此默认 Release 不复制这些瓦片。
- 管理员可以从自己有权使用的本地 PalOps 安装导入完整离线瓦片；未导入时固定 POI 和服务器标记仍可在深色无底图模式中工作。

## 验证重点

- Palpagos 与 World Tree 切换后标记应落在对应地图。
- 三种语言固定 POI 必须各 1,251 条并保持相同 ID 和坐标。
- 发布包不得包含未经确认的 PalOps 栅格瓦片。
- GitHub Actions 应通过前端测试、PalOps/MapLibre 资源同步器测试及 Linux/Windows 发布构建。

完整比较：`v1.3.0-custom.0.8.38...v1.3.0-custom.0.8.39`
