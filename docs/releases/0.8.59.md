# PalPanel patch 0.8.59

## 任务管理前端

本版为 0.8.58 事件任务引擎补齐面板管理界面。

新增 `/operations-tasks` 页面：

- 任务定义创建、编辑、复制和归档。
- 每日、每周、永久一次周期配置。
- 事件类型、目标数量、奖励积分、数量字段和 Payload JSON 过滤条件编辑。
- 捕获、击杀、在线和 Boss 任务快速模板。
- PlayerUID 任务进度查询。
- 完成比例、奖励状态和奖励失败原因展示。
- 待发或失败奖励人工重试入口。
- 归档任务显示开关。

侧边栏“积分系统”现在包含“积分账户”和“任务系统”两个子页面。

## 兼容性

- 不修改 0.8.58 的任务数据库结构。
- 不新增运行时 API 路由；继续使用 0.8.58 已纳入 OpenAPI 的六个任务接口。
- 原 `/tasks` 路径继续用于后台作业和计划任务队列，运营任务使用 `/operations-tasks`，避免冲突。
