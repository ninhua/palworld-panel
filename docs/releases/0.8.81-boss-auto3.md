# Palworld Panel 0.8.81 Boss 自动执行维护增量 3

本增量以 `0.8.81-boss-auto2` 为前置基线。

## 新增控制动作

复用现有接口：

```text
POST /api/boss/summons/{summon_id}/transition
```

暂停后续自动波次：

```json
{"status":"pause"}
```

恢复自动波次：

```json
{"status":"resume"}
```

跳过当前第一条等待波次：

```json
{"status":"skip_current"}
```

三个动作均返回更新后的召唤记录。

## 安全限制

- 仅处理 `metadata.auto_execute=true` 的召唤。
- 已完成、失败或取消的召唤不能控制。
- 控制动作使用 `boss-auto2` 的数据库租约，与自动执行器互斥。
- `skip_current` 不会跳过正在执行的波次。
- 存在活动波次、运行中执行记录或 `uncertain` 记录时拒绝跳过。
- 跳过动作只选择位置最靠前的 `pending` 波次。
- 暂停和继续状态持久化到 `metadata_json`，面板重启后继续生效。
- 暂停、继续和跳过均写入原有 Boss 召唤审计事件。

## 当前限制

本维护增量提供后端控制能力，Boss 页面按钮尚未加入。可以通过诊断控制台或 API 客户端调用。
