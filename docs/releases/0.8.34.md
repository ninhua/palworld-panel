# PalPanel 自定义版 0.8.34

发布日期：2026-07-29

## 新增

- 新增“存档差异”页面，比较当前激活存档源的两次成功索引。
- 支持玩家、公会、基地、帕鲁、容器和全局物品数量六类变化。
- 支持按类别、名称、ID、字段和物品 ID 搜索，单次最多返回 500 项。
- 每次成功索引自动形成快照；升级后首次打开页面会将已有成功索引补录为基线。

## 快照策略

- 快照保存结构化索引，不复制或修改原始 `.sav`，不能替代存档备份。
- 相同存档指纹不会重复保存。
- 不同存档源按世界目录不可逆哈希隔离，不能跨世界比较。
- 每个世界默认保留最近 24 份，单份压缩文件最多 128 MiB，总压缩体积最多 512 MiB。

## 安全

- 快照目录权限为 `0700`，快照和清单文件权限为 `0600`。
- 保存前移除存档路径、玩家 IP、Ping 和原始解析载荷。
- API 不返回私密目录、原始索引或内部压缩文件 SHA-256。
- 读取时校验压缩文件 SHA-256、schema、世界键、快照 ID 和指纹。
- 快照 ID 使用固定格式并映射到受管目录，拒绝路径穿越。

## 接口

- `GET /api/save/history`
- `GET /api/save/history/diff?from=<id>&to=<id>&category=<category>&q=<query>`

## 验证重点

- 列表和差异响应不得出现 `source_path`、玩家 IP、Ping、原始解析载荷或归档 SHA-256。
- 切换到另一存档源后不得看到原存档源的快照。
- 修改、截断或替换快照文件后，差异接口必须拒绝读取。
- 玩家升级、帕鲁新增、容器内容变化和全局物品增减应分别计入正确类别。
- GitHub Actions 执行 Go、前端、OpenAPI、Linux/Windows 打包和安全检查。

完整比较：`v1.3.0-custom.0.8.32...v1.3.0-custom.0.8.34`
