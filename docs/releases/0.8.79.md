# PalPanel Patch 0.8.79

本版补齐玩家任务入口和在线时长任务自动结算。

## 新增

- 游戏聊天命令：`任务`、`我的任务`、`任务进度`。
- 支持任务分页和关键词搜索，例如 `任务 2`、`任务 捕捉`。
- 新增签名接口 `POST /api/integrations/game/tasks/query`。
- 每 30 秒通过 PalDefender 玩家目录采样在线玩家。
- `PLAYER_ONLINE` 事件按完整分钟自动推进任务。
- 玩家下线时补结算最后采样区间，不足一分钟秒数跨会话保留。
- 在线追踪状态写入 SQLite，面板重启后安全恢复。
- 新增 `GET /api/tasks/online-tracking` 管理接口。
- 游戏事件桥接页面显示在线采样人数、累计分钟和错误信息。

## 安全与幂等

- 面板停机时间不会被计入在线时长。
- 单次采样最多计入 90 秒，避免长时间断连后过量累计。
- 在线分钟事件使用稳定哈希 ID，异常重试不会重复推进任务或发放奖励。
- 游戏内任务查询只读取当前玩家任务，不修改进度。
