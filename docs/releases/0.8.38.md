# PalPanel 自定义版 0.8.38

发布日期：2026-07-29

## 修复

- 修复合作房主存档转移时，`palworld-uid-remap` 把 `worldSaveData.ItemContainerSaveData[n].Value.CustomVersionData` 中的固定房主 UID 哨兵字节误判为未重写玩家引用并中止迁移的问题。
- 该字段继续原样保留，不执行二进制搜索替换；迁移结果增加对应验证警告。

## 安全边界

- 只允许 `Level.sav` 的精确 `ItemContainerSaveData[n].Value.CustomVersionData` 路径。
- 只允许 source candidate `00000000-0000-0000-0000-000000000001`。
- 任意其他 opaque source/target UID、RawData、unknown bytes、trailing bytes 和相似路径继续阻止迁移。
- typed UID 数量转移、玩家文件重命名、输入清单二次校验、语义指纹和双重 round-trip 验证保持不变。

## 升级注意事项

- 完整包更新会直接安装新版 `bin/palworld-uid-remap`。
- exec 热更新只替换 PalPanel 主程序；首次再次执行房主迁移时，新主程序会按嵌入的 SHA-256 从同版本 Release 下载并原子替换旧 helper。运行目录只读或无法访问 Release 时，应使用完整包更新。

## 验证重点

- 原报错路径应完成迁移，并在 verification warnings 中说明 CustomVersionData 元数据保持不变。
- 把同一 UID 放入 `RawData` 或相似但非精确路径时仍必须失败。
- 普通自定义 source UID 或 target UID 出现在 CustomVersionData 时仍必须失败。
- GitHub Actions 应通过 UID remapper Rust 测试、Go/前端测试及 Linux/Windows 发布构建。

完整比较：`v1.3.0-custom.0.8.37...v1.3.0-custom.0.8.38`
