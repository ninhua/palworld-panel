# Palworld Panel 0.8.94

## 库存可信归属与世界容器降噪

- 库存管理默认只聚合能够确认归属到玩家、据点或公会的容器。
- 野外宝箱、地图对象、掉落容器以及伪装成玩家/据点但无法匹配索引实体的容器不再进入默认总量。
- 新增公会库存归属筛选；未归属容器保留在“诊断：隐藏容器”范围中，不会丢失底层排查能力。
- 库存响应增加可信标记、归属判定原因及已隐藏容器、位置、物品种类和数量统计。
- 无人时段库存净增加改用同一套可信归属分类，避免野外刷新被误判为据点生产或库存增长。
- 无人时段状态存储升级到 v2 命名空间，安装后会重新建立可信库存基线，不混用旧版全世界容器基线。
- 前端默认明确显示“可信库存”，并提示被隐藏的世界噪声数量。

## 兼容性

- `/api/inventory?owner_type=all` 仍为默认查询，但语义改为“全部可信归属”。
- `owner_type=unknown` 继续可用，作为显式诊断视图。
- 原有响应字段保留；新增字段均为向后兼容扩展。
- 数据库无需迁移，无人时段旧状态不会删除，只是不再由 v2 逻辑读取。
