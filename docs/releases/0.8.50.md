# PalPanel 0.8.50

## 语义化存档事件

- 存档差异页新增“发生了什么”事件视图，不再只平铺字段名与前后值。
- 按玩家、装备与物品、帕鲁、据点和公会分组显示事件，并保留原始字段差异折叠区用于审计。
- 可推断玩家升级/降级、加入或离开公会、改名，以及玩家首次出现或从快照中消失。
- 按容器归属聚合物品，显示哪个玩家或哪个据点获得、失去、消耗或转出何种装备与物品，以及数量前后变化。
- 显示玩家或据点获得/失去帕鲁、帕鲁归属转移、等级/星级成长、工作位置与状态变化和被动词条变化。
- 显示据点创建/消失、建筑数量增减、工作帕鲁加入/离开、存储容器数量、状态与坐标变化，以及公会成员、据点和会长变化。
- 所有事件均明确标记为两份快照之间的推断；“获得帕鲁”可能来自捕获、孵化、交易或导入，不能当作精确时间线日志。

## 地图标记辨识度

- 固定 POI 与服务器动态实体改用不同形状、颜色、描边和字形，不再全部显示为相似圆点。
- 快速传送、地牢、高塔、区域头目、敌人营地、资源、收集品、NPC、帕鲁地点、玩家、据点和自定义标记均有独立视觉编码。
- MapLibre 和非 WebGL 兼容瓦片模式共用同一套图标语义，选中项增加独立高亮光环。

## 帕鲁地图位置

- 世界地图默认显示存档索引中具有有效坐标的帕鲁，并展示等级、位置类型和状态。
- 地图接口返回帕鲁位置来源、数量和快照更新时间；页面按现有自动刷新周期重新读取。
- 当前数据来自最近一次成功存档索引，会随服务器自动存档和索引更新，属于近实时快照，不是进程内存级野生帕鲁实时追踪。
