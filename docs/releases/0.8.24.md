# PalPanel 自定义版 0.8.24

本版本补充 PalDefender 运行时 RCON 命令诊断入口。

## 新增

- 在“安全设置 → PalDefender 状态”中增加“实际 RCON 命令”检查。
- 点击检查后由面板执行 `/getrconcmds`，原样显示当前游戏进程返回的命令目录。
- 同时显示实际执行的命令格式，便于确认当前 PalDefender 是否需要省略 `/` 前缀。
- 请求失败时直接显示后端返回的诊断错误。

## 行为说明

- 此功能只用于检查，不参与传送、删除物品等 GM 操作。
- 不会根据检查结果自动禁用按钮、改写命令或改变操作流程。
- 页面不会自动轮询；仅在管理员主动点击“检查”时请求当前进程。

## 验证建议

1. 确认 PalDefender 与 UE4SS 均显示“启动日志已确认”。
2. 点击“实际 RCON 命令”的“检查”按钮。
3. 在原始输出中搜索 `tp`、`delitems` 等需要核对的命令。
4. 如果命令未列出，优先检查当前进程实际加载的 PalDefender DLL 与配置，而不是仅依据安装目录中的版本文件。
