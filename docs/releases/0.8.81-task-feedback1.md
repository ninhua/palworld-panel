# 0.8.81-task-feedback1

## 游戏内任务完成反馈

任务奖励此前只写入积分账本，除主动聊天命令外不会向玩家发送完成提示。本维护增量增加持久化任务完成通知队列。

完成任务且奖励成功后，面板通过现有 PalDefender 私人消息通道发送：

```text
【任务完成】任务名称（当前进度/目标），奖励N积分已到账。
```

零积分任务发送普通完成消息。普通任务进度不会发送消息。

## 可靠性

- 通知主键为 `task_id + player_uid + cycle_key`，同一周期只发送一次。
- 多进程通过 SQLite 条件更新抢占待发送记录。
- 玩家离线或发送失败时每 30 秒重试。
- 进程在发送中中断时，1 分钟后恢复为可重试状态。
- 积分奖励未成功前不会发送“已到账”提示。
- 启动时记录激活时间，不补发旧版本已经完成的历史任务。

## 数据表

新增：

- `operations_task_completion_notification_meta`
- `operations_task_completion_notifications`

无需手动迁移，面板启动时自动创建。
