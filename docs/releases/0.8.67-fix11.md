# 0.8.67-fix11

本修复包基于 `custom-stable` 提交 `24375dd68902446b59f5fa934566ed4984497c43`，不改变运行时 `patchVersion`，用于收尾上游 v1.3.1 合并后的功能入口和构建流程。

## 存档迁移

- 在存档中心恢复上游多人“玩家迁移向导”入口。
- 保留自定义分支原有的单人“主机迁移”入口，两套迁移流程可并存使用。
- 多人向导继续使用已合入的 UID 模式检测、冲突预检、完整备份、失败回滚和任务中心进度。

- 离线或镜像依赖模式不再被第二次无参数 Cargo 调用绕过。

## GitHub Actions

- CI、标准 Release 和自定义 Release 的 Linux/Windows 构建显式安装 Rust 工具链。
- Linux CI 独立运行 `cargo test --locked`。
- 前端漏洞检查改用仓库内的 `npm run audit:ci` 策略。
