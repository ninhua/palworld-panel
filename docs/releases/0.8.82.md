# PalPanel v1.3.1-custom.0.8.82

基于 upstream v1.3.1，包含自定义功能和修复。

## 新增（自 v0.8.81）

- **管理 API Key 访问诊断控制台** — `RequireInteractiveAdmin` 现在也接受 API Key，管理员可以用 API Key 在内网访问 HTTP 诊断台/Shell 执行
- **PalPanelBridge 增强** — 在线玩家查询、UE4SS 属性探测、桥接响应时间戳、玩家组件/集合/函数探测、函数参数检查等

## 之前叠加的功能

### Boss 活动系统
- boss-auto1/2/3 — 自动多波次执行、数据库租约去重、波次暂停/恢复/跳过
- boss-retry1 — 失败波次安全重试
- boss-guard1 — 活动互斥守护

### 袭击系统
- raid-base1 — 袭击与 Boss 领域拆分、据点绑定、混合波次

### 任务系统
- task-feedback1 — 游戏内任务完成通知，在线/离线追踪

## 修复
- SaveSourcesDir 为空时跳过 save import inspection 清理
- 移除路由注册时的 taskService 预初始化，修复 Windows test.db 文件锁
- queryOnlinePlayers 通过 PalUtility 正确查询
- 多种桥接稳定性修复
