# Palworld Panel 0.8.66

## Boss 管理界面

新增 `/boss` 管理页面，接入 0.8.64 已提供的 Boss 基础 API：

- 奖励方案创建、编辑、启用和归档；
- 从 PalDefender 物品目录直接选择奖励物品；
- 从 PalDefender 帕鲁模板目录直接选择奖励模板；
- Boss 模板创建、编辑、启用和归档；
- 从本地帕鲁目录搜索并选择 Pal ID；
- 配置等级、数量、生命/攻击/防御倍率、生成半径、冷却、捕获限制、坐标和关联奖励；
- 创建 `record_only` 手动召唤记录；
- 中文显示召唤状态并执行合法状态流转；
- 查看每条召唤记录的追加式状态审计事件。

当前版本仍不会调用 PalDefender 或 RCON 实际生成 Boss。页面会明确提示“仅记录模式”。

## 任务中文显示

任务页面继续使用英文事件代码作为稳定存储值和事件匹配键，但所有主要界面改为中文显示：

- 任务事件类型；
- 周期；
- 数量字段；
- 启用、停用和归档状态；
- 玩家进度和奖励状态。

内部事件代码仍以次要说明显示，便于配置事件桥接器，不再作为主要名称。
