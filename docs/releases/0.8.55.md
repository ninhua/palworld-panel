# PalPanel 0.8.55

发布日期：2026-07-31

## 新增功能

- 新增AstrBot插件旧积分SQLite数据库检查与迁移入口。
- 积分系统页面支持上传 `palpanel.sqlite3`，先预览、后确认迁移。
- 迁移旧账户余额、PlayerUID绑定关系和签到去重记录。
- 新增迁移批次和来源账户审计表。
- 旧余额重复上传采用差额导入，不会重复加分。

## 安全与一致性

- 迁移接口只接受上传文件，不接受任意服务器文件路径。
- 仅管理员浏览器会话可以执行检查和迁移。
- 上传限制为64 MiB，并检查SQLite文件头和必要表结构。
- 未绑定PlayerUID的QQ账户不会导入。
- 旧库余额下降时不会自动扣除面板积分。
- 每笔迁移积分都写入统一积分账本并带有QQ号和源文件SHA-256审计元数据。

## 行为变更

- 无。现有积分账户、游戏命令前缀、签到、预留和人工调整接口保持兼容。

## 升级说明

1. 当前仓库必须已经应用 `0.8.54` 增量包。
2. 将 `Palworld-Panel-overlay-v0.8.54-to-v0.8.55.zip` 解压到仓库根目录覆盖。
3. 执行后端测试和前端检查。
4. 首次打开积分页面时，迁移审计表会在需要时自动创建。
5. 正式迁移前停止AstrBot旧插件继续修改积分。

## 验证范围

- Go源码格式检查。
- 积分核心包隔离编译。
- AstrBot数据库结构、重复导入、差额导入和签到去重测试源码。
- TypeScript语法和页面接口检查。
- ZIP路径、清单和SHA-256校验。
