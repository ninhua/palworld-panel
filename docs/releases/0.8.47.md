# PalPanel 自定义版 0.8.47

## 地图资源 Release 完整包修复

- 修复资源仓库源码分支不包含 POI JSON 时，构建在下载 GitHub Release 附件前提前失败的问题。
- GitHub Release 附件现在可以作为完整地图资源包，同时提供 POI、WebP 瓦片、图标、元数据和许可证。
- 新增 `.tar.zst` 与 `.tzst` 归档支持，兼容 `palops-map-assets.tar.zst`。
- 自动选择 Release 附件时识别 `.tar.zst`；生成的运行时清单记录实际标签和附件名。
- 保留旧布局兼容：源码 POI + Release 瓦片、源码完整资源包和本地离线资源仍可使用。
- Linux Actions 显式安装 `zstd`；Windows Actions 通过 MSYS2 安装 `mingw-w64-x86_64-zstd`。
- 后端、OpenAPI 和前端契约版本同步为 `0.8.47`。

新发布标签：`v1.3.0-custom.0.8.47`。
