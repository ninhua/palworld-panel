# 0.8.72

## 签到规则完整配置

- 新增每日基础积分配置。
- 新增连续签到开关、每日递增奖励和递增封顶天数。
- 新增周期奖励间隔与额外积分，填 `0` 可关闭周期奖励。
- 新增签到、积分查询和帮助命令别名。
- 新增“同时允许无前缀命令”，默认同时识别 `签到` 与 `!签到`。
- 玩家详情新增签到历史，拆分显示基础、连续和周期积分。

## 游戏内签到修复

- 新增 PalDefender 日志内置桥接，自动读取聊天日志并执行积分命令。
- 支持中文冒号、带时间/日志等级前缀以及包含 PlayerUID/UserID 的常见聊天格式。
- 游戏回复继续通过 PalDefender 私人消息发送。
- 新增桥接状态、日志开关、最近观察和一键修复入口。
- 当天首次签到成功后派生 `CHECKIN_COMPLETED` 任务事件；重复签到不会推进任务。

## 捕捉与其他任务事件

桥接器将新增日志转换为：

```text
PAL_CAPTURED
PAL_KILLED
PLAYER_LOGIN
ITEM_CRAFTED
PLAYER_CHAT
```

捕捉事件包含 `count=1`、`pal_id` 和 `pal_name`，可以直接驱动捕捉任务。击杀任务依赖 PalDefender 实际输出的死亡日志格式；管理页面会显示最近日志样本，便于确认过滤字段。

## 数据迁移

`economy_checkins` 会自动增加：

```text
base_points
streak_bonus
cycle_bonus
streak_day
```

旧签到记录会把原 `points` 回填为 `base_points`，不会重复记账。

新增桥接偏移和观察表，用于重启续读与问题排查。首次启用从日志末尾开始，不回放旧事件。

## 修复补充：补丁特性契约

- `/api/patch/info` 的 `features` 现在按首次注册顺序稳定去重，避免基础列表和模块 `init()` 重复追加同一特性。
- 恢复此前升级时遗漏的存档迁移向导、上游迁移主界面、PalPanelBridge 运行诊断和中国时区默认值特性标识。
- 本修复不改变运行时版本号 `0.8.72`，也不删除任何既有功能；仅修复补丁元数据输出和回归保护。
