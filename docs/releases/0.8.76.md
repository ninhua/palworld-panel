# PalPanel patch 0.8.76

## 任务事件诊断

任务页面新增“任务诊断”工作区。管理员可以输入事件类型、PlayerUID、事件ID和Payload，在不写入任何数据的情况下检查全部任务定义。

诊断会逐条说明未命中的原因：

- 事件类型不一致；
- 任务已停用或归档；
- 缺少PlayerUID；
- Payload缺少过滤字段；
- 过滤值不一致；
- 缺少数量字段；
- 数量不是正整数；
- 事件ID已经处理；
- 当前周期任务已经完成；
- 事件会推进任务以及预计新增进度。

每个任务定义增加“测试任务”按钮，可自动填入事件类型、过滤条件和数量字段示例。

## 事件重放

新增受 `players:write` 权限保护的任务事件重放入口。重放必须提供稳定的 `event_id`、事件类型和PlayerUID，并继续使用现有任务事件回执保证幂等。

实际推进前，面板会明确提示该操作可能写入任务进度并发放积分奖励。相同事件ID再次执行不会重复推进。

## API

新增：

```text
POST /api/tasks/diagnostics/evaluate
POST /api/tasks/diagnostics/replay
```

OpenAPI操作数由338增加到340。
