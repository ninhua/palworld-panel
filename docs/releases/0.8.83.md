# PalPanel v1.3.1-custom.0.8.83

基于 upstream v1.3.1，包含自定义功能和修复。

## 新增（自 v0.8.82）

### player-identity-fix1 — 玩家身份修复

- 统一 Palworld PlayerUID 紧凑格式、8-8-8-8 格式和 UUID 为 32 位大写十六进制
- 统一 Steam64 和 `steam_` 前缀用于日志身份匹配
- 自动合并积分账户中的重复 PlayerUID，保留并汇总双方余额和账本
- 合并任务进度、任务奖励、事件回执和在线时长记录
- 修复 PalDefender 登录日志把括号内 IP 当做玩家昵称
- PalDefender `[Player::SendMsg::*]` 系统回执不再进入解析失败死信
- 新写入数据通过 SQLite 规范化规则避免再次分裂

## 之前叠加的功能

- 管理 API Key 访问诊断控制台
- PalPanelBridge 增强
- Boss 活动系统（auto1/2/3、retry1、guard1）
- 袭击系统（raid-base1）
- 任务系统（task-feedback1）

## 修复
- SaveSourcesDir 为空时跳过 save import inspection 清理
- 移除路由注册时的 taskService 预初始化，修复 Windows test.db 文件锁
