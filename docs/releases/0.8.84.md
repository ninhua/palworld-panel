- PalTemplate 目录直接选择模板 + 组合筛选
- 保存固定世界坐标 Boss 定义

- 统一 PlayerUID 格式、Steam64 日志匹配
- 积分账户自动合并去重

- PalDefender 登录日志 IP 误识别修复
