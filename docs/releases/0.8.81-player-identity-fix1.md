# 0.8.81-player-identity-fix1

本维护增量修复 PalDefender 日志身份解析和 PlayerUID 格式分裂，不修改运行时补丁版本。

## 行为变化

- GUID 类型 PlayerUID 使用 32 位大写紧凑格式作为规范键。
- Steam64 数字和 `steam_` 日志标识可以正确匹配。
- 积分账户、任务进度、在线时长和游戏事件统一使用等价 PlayerUID 比较。
- 已存在的重复积分账户事务合并并汇总余额。
- 重复账本引用不会丢失，而是增加身份合并后缀。
- 登录日志只提取平台 ID，不再把 IP 地址作为昵称。
- PalDefender 系统回执日志不再生成待处理死信。

## 数据迁移

首次加载 economy、tasks 或 gameevents 服务后，后台维护器执行一次幂等迁移，并在 `palpanel_identity_migrations` 中记录完成状态。

迁移覆盖：

- `economy_accounts`
- `economy_ledger`
- `economy_checkins`
- `economy_reservations`
- `economy_command_events`
- `operations_task_progress`
- `operations_task_event_receipts`
- `operations_task_rewards`
- `operations_task_online_tracking`
- `game_events`
- 游戏事件桥接观察记录及死信

## 注意事项

- 应用前备份 SQLite 数据库。
- 余额采用保守策略汇总，不自动判定两边积分是否属于业务重复发放。
- 旧 `PLAYER_LOGIN` 未匹配死信需要在重启后手动或批量重放。
