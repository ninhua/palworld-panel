# PalPanel patch 0.8.78

## 游戏事件桥接可靠性

- 将 PalDefender 日志读取游标持久化到 SQLite，并保存稳定文件前缀指纹。
- 面板重启后继续读取上次偏移，不再依赖进程内状态。
- 检测日志截断、同名文件替换和轮转，自动安全重置游标。
- 记录游标恢复审计和每个日志文件的累计恢复次数。

## 事件死信

- 新增 `game_event_bridge_dead_letters` 表。
- 解析失败、玩家未匹配和处理失败的事件不再静默丢失。
- 保存原始事件 ID、Payload、玩家提示、日志原文、失败原因和重试次数。
- 死信可人工指定 PlayerUID 后重放，或标记为忽略。
- 重放继续使用原始事件 ID，复用积分、任务和商城现有幂等保护。

## 管理界面

- 积分页面显示待处理死信、持久化游标文件和轮转恢复数量。
- 提供死信详情、Payload、日志样本、人工 PlayerUID、重放和忽略操作。
- 提供持久化游标明细和最后恢复原因。

## API

新增：

```text
GET  /api/game-events/bridge/dead-letters
POST /api/game-events/bridge/dead-letters/{id}/replay
POST /api/game-events/bridge/dead-letters/{id}/dismiss
```

OpenAPI 操作数量更新为 346。
