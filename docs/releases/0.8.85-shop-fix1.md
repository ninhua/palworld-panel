# Palworld Panel 0.8.85 商城修复增量 1

## 商品上架

- PalDefender 物品商品改为从服务器物品目录选择，可搜索中文名和内部 ID，并逐项设置数量。
- PalDefender 帕鲁模板商品改为从模板目录选择。
- 帕鲁模板保留索引文件、模板分类、综合分级、用途分类、分类标签、毕业用途和模板状态组合筛选。
- 自动交付 Payload 根据选择结果生成，只读预览，不再要求管理员手写内部 JSON。

## 兑换与账户解析

- 商城操作同时使用 PlayerUID 与 SteamID 解析积分账户。
- 当前 PlayerUID 仅命中零余额账户、SteamID 唯一命中已有余额账户时，安全使用已有账户。
- 不自动合并身份冲突账户；多个 SteamID 候选或双方均有余额时保留警告并阻止不安全选择。
- 游戏内积分不足提示包含商品单价、数量、所需积分、可用积分、未结订单预留积分、请求身份、实际账户和诊断编号。

## 面板诊断

- 新增 `shop_redemption_attempts` SQLite 账本，失败发生在订单创建前也会记录。
- 商城页面新增“兑换诊断”标签，可按玩家身份和结果筛选。
- 诊断记录显示账户匹配策略、请求 PlayerUID、SteamID、实际账户、余额、预留、价格、失败码和订单 ID。
- 新增管理接口：`GET /api/shop/redemption-attempts`。

## 兼容性

- 当前运行时补丁版本保持 `0.8.85`，以维护增量形式叠加。
- 现有商品、订单、库存、积分预留和交付审计表不迁移。
- 新诊断表由商城服务按需幂等创建。
- 新接口尚未写入生成 OpenAPI 合同，后续正式版本升级时统一同步。
