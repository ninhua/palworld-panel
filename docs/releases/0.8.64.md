# Palworld Panel Overlay 0.8.64

升级范围：`0.8.63 -> 0.8.64`

## 新增

- Boss 奖励配置 CRUD 与归档。
- Boss 模板 CRUD 与归档。
- 等级、数量、属性倍率、生成半径、捕获、冷却、奖励和坐标配置。
- 幂等手动召唤记录。
- `pending / active / completed / failed / cancelled` 状态机。
- 召唤状态追加式审计事件。
- Boss 汇总统计。
- 13 个 Boss API 操作及 OpenAPI 类型。

## 数据安全

- 模板和奖励删除采用归档，不破坏历史召唤快照。
- 召唤记录保存模板关键字段快照，后续修改模板不会篡改历史。
- `request_key` 唯一约束防止重复创建。
- 终态召唤不可再次流转。

## 当前限制

- 本版 `execution_mode` 固定为 `record_only`。
- 不调用 PalDefender 或 RCON 实际生成 Boss。
- 不包含多波次编排、定时召唤、预警广播和参与者自动结算。
- 奖励仅保存配置，不在本版自动发放。
