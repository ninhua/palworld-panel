# Palworld Panel 0.8.82 Boss 固定坐标召唤增量 1

本增量在袭击模块之外增加独立的 Boss 管理页面。

## 功能

- 新增 `/bosses` 页面和“Boss 管理”导航。
- Boss 定义保存固定世界坐标、PalTemplate、数量、生成半径、捕捉规则和冷却时间。
- PalTemplate 必须从服务器模板目录选择，不允许手工输入文件名。
- 模板目录复用新玩家礼包的索引、分类、综合分级、用途、标签、毕业用途和模板状态组合筛选。
- 立即召唤复用现有 PalDefender `/summon` 执行器、执行账本、数据库租约和全局活动锁。
- Boss 定义及召唤记录通过 `activity_kind=fixed_boss` 与据点袭击分离。
- PalTemplate 缺失时阻止执行，要求管理员重新选择。

## 兼容性

- 不修改现有袭击接口、SQLite 表和波次状态机。
- `/boss` 继续作为袭击兼容地址；独立 Boss 页面使用 `/bosses`。
- 后端继续复用现有 boss-prefixed API 和表名，以避免数据迁移和执行状态分叉。

## 限制

- 本增量只实现管理员手动固定坐标召唤。
- Boss 死亡检测、参与统计、奖励结算和定时刷新尚未实现。
- 未连接真实 Palworld/PalDefender 进行端到端测试。
