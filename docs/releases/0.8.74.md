# 0.8.74

诊断控制台响应显示增强版本。

## 响应 JSON 识别

- HTTP 响应体是有效 JSON 时自动切换为格式化显示。
- 忽略响应体开头的 UTF-8 BOM 和外围空白。
- 不依赖 `Content-Type`；即使接口返回错误的媒体类型，只要响应体是有效 JSON 仍可格式化。
- 空响应、截断后无法解析的 JSON 和普通文本继续按原始响应显示。

## 显示模式

有效 JSON 响应支持四种视图：

- 格式化 JSON：两空格缩进，默认视图。
- 压缩 JSON：单行输出，便于复制和比较。
- 树形查看：对象和数组节点可点击展开或折叠，并区分字符串、数字、布尔值和 null。
- 原始响应：保留服务端返回的原始文本。

响应状态、耗时和响应头始终保留。复制响应和复制完整记录会使用当前视图对应的文本；树形视图复制时使用格式化 JSON。

## 兼容性

- 没有新增或删除后端 API。
- 历史记录仍保存服务端原始响应；载入历史时重新识别 JSON，不会改写历史数据。
- 自定义诊断模板、请求头树形编辑和历史去重行为保持不变。

## 修复补充：主机迁移存档保护

- 主机迁移切换服务器世界前，先把 `DedicatedServerName` 当前指向的完整世界复制为独立的导入存档源。
- 备份在服务器停止后生成；备份复制、`Level.sav` 校验或数据库登记失败时，迁移立即中止。原服务器此前处于运行状态时会重新启动原世界。
- 迁移后不会删除旧服务器世界目录；存档中心同时保留可见的“主机迁移前备份”，便于人工恢复和差异分析。
- 当前运行世界由主机迁移生成时，存档中心会根据迁移源 ID 与世界目录 ID 的确定性映射恢复迁移名称，并同步写回内置 `server` 存档源。
- 修复迁移成功后活动存档仍显示“当前服务器存档”、用户填写的迁移名称只出现在非活动副本上的问题。
- 新增 `host-save-migration-pre-switch-backup` 和 `host-save-migration-server-name-sync` 特性标识。
