# PalPanel patch 0.8.56

## 新增

- 签名游戏事件入口 `/api/integrations/game/events`。
- 独立游戏事件账本，按 `event_id` 幂等去重。
- 失败事件使用同一 ID 重试，已完成事件不会重复执行。
- `PLAYER_CHAT` 事件接入积分命令执行器。
- 命令回执通过 PalDefender REST 向在线玩家发送。
- 面板只读游戏事件查询接口。

## 与参考功能的关系

该版本是任务、积分商城、抽奖、Boss 掉落、定时召唤和攻击波次的统一事件基础。`0.8.56` 只自动处理玩家聊天命令，其他事件先可靠落库，后续版本再逐项增加规则和奖励执行。

## 配置

复用现有 AstrBot 集成的面板 ID 与共享密钥，不新增第二套密钥。PalDefender 私聊回执要求 PalDefender REST API 已启用，且面板令牌包含玩家消息发送权限。

## 已知限制

- 本版不包含 PalDefender 日志/事件自动转发器；调用方需要按文档签名上报。
- 非 `PLAYER_CHAT` 事件暂不执行任务进度或奖励。
- 玩家离线、PlayerUID 无法匹配或 PalDefender REST 不可用时，命令仍会执行，但回执状态会记录为未发送。
