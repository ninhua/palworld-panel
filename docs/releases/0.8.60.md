# PalPanel patch 0.8.60

## 版本契约同步修复

本版修复前端 `check:api-types` 因自动生成文件未随 OpenAPI 版本更新而失败的问题。

同步更新：

- 后端运行时 `patchVersion`：`0.8.60`
- `docs/openapi.yaml` 中 `PatchInfo.patch.version`：`0.8.60`
- `frontend/src/api/generated/contracts.ts` 中生成的补丁版本字面量：`0.8.60`

## 回归保护

新增 `TestPatchVersionArtifactsStayInSync`：

- 检查运行时补丁版本与 OpenAPI 常量一致。
- 检查运行时补丁版本与生成的 TypeScript 合约一致。
- 生成文件漏提交时，后端 `go test ./...` 也会给出明确错误。

本版不修改数据库结构、运行时 API 路由或业务行为。

## npm audit

安装日志中的两个 moderate 漏洞不属于本次 CI 失败原因。本版没有执行 `npm audit fix --force`，避免在未审查依赖变更的情况下引入破坏性升级。
