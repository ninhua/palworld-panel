# PalPanel 0.8.54

发布日期：2026-07-31

## 新增功能

- 游戏命令前缀改为数据库配置，默认使用 `!`。
- 命令前缀可设置为任意不含空白或控制字符的字符串，最多 16 个 Unicode 字符。
- 支持将命令前缀保存为空；玩家可直接发送 `签到`、`积分`、`帮助`。
- 无前缀模式只匹配已知命令，普通聊天不会误触发，也不会创建积分账户或污染命令去重表。
- 每日签到奖励改为积分系统配置，可在面板中修改为 `0` 到 `1000000`。
- 新增积分管理页面，提供运营汇总、配置、账户搜索、流水查看和人工积分调整。
- 首次建立积分配置时兼容 `PALPANEL_GAME_COMMAND_PREFIX`、`PALPANEL_DAILY_CHECKIN_POINTS` 和 `PALPANEL_OPERATIONS_TIMEZONE` 环境变量。

## 新增接口

- `GET /api/economy/config`
- `PUT /api/economy/config`

`PUT /api/economy/config` 需要 `config:write` 权限。

## 界面变更

- 世界管理导航增加“积分系统”。
- `/economy` 页面可直接修改命令前缀和签到积分。
- 路由标题增加无翻译键回退能力，新模块可以在不修改整份语言包的情况下显示中文标题。

## 数据与升级

- 新增 `economy_settings` 表，不修改已有积分账户、流水、签到或预留数据。
- 从 `0.8.53` 升级时会自动建立设置表。
- 如果设置表首次建立时存在环境变量，则使用环境变量作为初始值。
- 设置一旦写入数据库，后续启动不会被环境变量覆盖。
- 默认升级结果仍是 `!签到`、`!积分`、`!帮助`，不会改变已有玩家习惯。

## 验证范围

- Go 源文件执行 `gofmt`。
- 积分核心包和 API 文件通过隔离编译检查。
- 自定义前缀、空前缀和普通聊天不误触发测试通过。
- 前端新增及覆盖文件通过 TypeScript/TSX 语法检查和隔离类型检查。
- SQLite 设置表、默认值、空字符串前缀和更新语句通过实际 SQLite 验证。
