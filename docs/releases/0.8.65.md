# Palworld Panel 0.8.65

## 任务编辑器

- “事件类型”由浏览器 `datalist` 改为真正的下拉选择框，避免部分浏览器不显示候选项。
- 提供捕获、击杀、在线时长、签到、Boss 参与、Boss 击杀、登录和制作物品等事件选项。
- 切换事件时，在数量字段仍为上一事件默认值的情况下，自动切换为 `count` 或 `minutes`。
- 每个事件选项显示用途和常见 Payload 字段提示。

## 商城商品编辑器

- PalDefender 物品商品可直接搜索面板物品目录并添加，不再要求手写物品 ID JSON。
- 每种已选物品可单独配置数量，支持删除和重新选择。
- PalDefender 帕鲁模板商品可直接读取模板目录、搜索并添加多个模板。
- 编辑旧商品时，会从已有 Payload 反向恢复已选物品和模板。
- 自动交付商品的 Payload 由面板生成，并提供只读预览。
- 人工交付商品仍可保存可选的自定义 JSON 元数据。

## Payload 说明

Payload 是商品或游戏事件携带的机器可读 JSON 数据：

- 商城物品商品：`{"items":[{"item_id":"PalSphere","count":10}]}`
- 商城帕鲁模板商品：`{"pal_templates":["starter_pal.json"]}`
- 任务过滤条件：用于匹配游戏事件中的字段，例如 `{"pal_id":"SheepBall"}`

商城订单数量会乘以物品数量，或重复整组帕鲁模板。

## 版本同步

运行时补丁版本、OpenAPI `PatchInfo` 常量和生成的 TypeScript 合约已统一更新到 `0.8.65`。
