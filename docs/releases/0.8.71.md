# 0.8.71

## Boss 预警广播

- 定时 Boss 计划进入预警窗口后，通过 PalDefender 重要广播发送到游戏内。
- 支持 `{{minutes}}`、`{{schedule}}` 和 `{{boss}}` 变量。
- 广播成功和失败均写入 `boss_schedule_events`。
- PalDefender 未安装、未加载、REST 未启用、Token 缺失或请求失败时，事件状态保持为 `failed`。
- 同一计划和同一计划时间在当前 PalPanel 进程内不会重复发送。

## 测试操作

新增：

```text
POST /api/boss/schedules/{id}/test-warning
```

Boss 页面中的每个计划新增“发送测试预警”按钮。测试使用与正式预警相同的文本渲染和 PalDefender 通道，并在审计中标记 `details.test=true`。

## 仍未实现

- Boss 实际生成仍为 `record_only`。
- 预警广播依赖 PalDefender REST 可用。
- PalDefender 接收广播后、审计写入前若进程异常退出，重启后可能再次发送同一计划预警；外部广播接口本身不提供幂等键。
