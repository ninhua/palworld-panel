# v1.3.0-custom.0.8.23

发布日期：2026-07-29（北京时间）

## 修复

- 修复 PalDefender RCON 返回 `Unknown command` 时，面板仍将传送、删除物品等操作记录为成功的问题。
- GM 命令遇到明确的 `Unknown command` 后，会兼容重试一次不带 `/` 前缀的 RCON 格式。
- 两种格式均被拒绝时，接口返回 `502 paldefender_rcon_command_rejected`，审计日志记录为失败，不再产生“HTTP 成功但实际未执行”的假成功。
- 成功响应会返回 PalDefender 实际接受的命令格式，便于审计和排障。

## 兼容性说明

- 官方 PalDefender 文档使用 `/tp`、`/delitems` 等带斜杠格式；部分实际 RCON 通道可能只接受不带斜杠的命令。本版本只在收到明确的 `Unknown command` 后进行兼容重试，不会对已接受或结果不确定的破坏性命令重复执行。
- 如果两种格式都失败，请在面板的 PalDefender 命令目录中检查 `/getrconcmds` 实时结果，并确认当前游戏进程实际加载的 DLL 与面板显示版本一致。

## 验证

- 新增带斜杠失败、不带斜杠成功的兼容回归测试。
- 新增两种格式均为 `Unknown command` 时必须返回失败的回归测试。
- Linux、Windows、前端、Go、依赖漏洞及安装包检查由 GitHub Actions 完整执行。

## 升级说明

- 可直接从 `0.8.22` 升级。
- 不需要修改 PalDefender 或 RCON 配置。
