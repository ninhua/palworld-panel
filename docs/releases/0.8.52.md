# PalPanel 0.8.52

## 发布身份递增

- `v1.3.0-custom.0.8.51` 的 Git 标签和 GitHub Release 均已存在，说明该版本已经完整发布。
- 项目将已发布标签视为不可变身份，因此重复运行同一版本的发布工作流会被主动拒绝。
- 本版本使用新的发布身份 `v1.3.0-custom.0.8.52`，完整继承 `0.8.51` 的功能与修复。

## 语义化存档事件

- 存档差异页按玩家、装备与物品、帕鲁、据点和公会展示可读事件，并保留原始字段差异用于审计。
- 显示玩家获得或失去的具体装备与物品、帕鲁归属和成长变化、据点建筑与仓储变化、公会成员和会长变化。
- 所有事件均为两份存档快照之间的状态推断，不伪造精确发生时间或捕获、孵化、交易等具体原因。

## 地图与帕鲁位置

- 固定 POI、玩家、据点、动态帕鲁和自定义标记使用不同形状、颜色、描边和字形。
- 世界地图显示存档索引中具有有效坐标的帕鲁，并标明位置来源、等级、归属、状态和快照更新时间。
- 帕鲁位置属于随服务器存档与索引刷新的近实时快照，不是进程内存级实时雷达。

版本：`0.8.52`
