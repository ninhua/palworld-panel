# PalPanel 自定义版 0.8.44

本版本修复世界地图在部分浏览器或远程桌面环境中的 WebGL2 初始化崩溃，增强存档差异页面对旧数据和空数组的兼容，并在面板侧栏显示当前自定义版本号。

## 世界地图兼容模式

- 在加载 MapLibre 6 前检查 WebGL2 上下文、最大视口尺寸和最大纹理尺寸。
- 浏览器返回空的 WebGL 能力数组时，不再让 MapLibre 读取空值的第一个元素并导致整张地图不可用。
- MapLibre 初始化、导航控件或部分运行时清理失败时，自动切换到不依赖 WebGL 的离线瓦片兼容模式。
- 兼容模式继续使用 `/map/palops/tiles` 中的自托管瓦片，支持地图层切换、0–3 级缩放、滚动浏览和 POI/服务器标记选择。
- MapLibre 正常可用时仍使用原来的 WebGL2 渲染路径。

## 存档差异稳定性

- 前端对历史列表、快照、统计、变化明细和字段数组进行响应归一化。
- 旧缓存或旧后端返回 `null` 数组时统一转换为空数组，避免 `items.length`、`items.map` 或 `fields.map` 触发页面级渲染错误。
- 缺失或无效的时间、指纹和计数使用安全显示值。
- 后端保证差异响应中的 `items` 与每条变化的 `fields` 始终编码为 JSON 数组，而不是 `null`。

## 版本显示

- 侧栏品牌区域通过 `/api/patch/info` 显示当前自定义版本，例如 `v0.8.44 · server control`。
- 版本接口异常时显示等待状态，不影响其他页面使用。

## 版本同步

- 后端补丁版本由 `0.8.43` 更新为 `0.8.44`。
- OpenAPI `PatchInfo.patch.version` 常量及前端生成契约同步为 `0.8.44`。
