# 0.8.87 Boss catalog selector maintenance 1

## Scope

- Uses the live PalDefender GM template list as the source of truth for Boss templates.
- Uses the starter-gift template index only as optional classification metadata.
- Keeps unindexed but usable PalDefender templates selectable.
- Loads a template document only when an unindexed template is selected, then validates `PalID`.
- Uses the PalDefender item catalog for Boss reward items.
- Adds the same item categories used by the starter-gift editor.
- Adds filtered PalTemplate selection for reward templates.
- Creates or updates a Boss reward record and links it through `reward_id`.
- Does not change raid templates or raid waves.
