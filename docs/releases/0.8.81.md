# 0.8.81

## Boss PalDefender RCON 执行适配层

- 新增 PalDefender `PalSummon` 文件执行器。
- 新增逐波“执行下一波”操作。
- 支持固定坐标、生成数量、生成半径和禁止捕捉。
- 支持使用已有 PalTemplate 文件，并校验 PalID 与等级和波次一致。
- 倍率不为 1 且未指定精确 PalTemplate 时安全阻止执行。
- 新增进程内执行锁，避免并行发送 Boss 召唤命令。
- 新增执行尝试账本，保存命令、响应、完成数量和失败原因。
- RCON 命令已发送但结果无法确认时标记 `uncertain`，禁止自动重试。
- 面板重启时遗留的 `running` 尝试自动转换为 `uncertain`。
- Boss 页面新增执行器状态、执行按钮、PalTemplate 文件配置和执行审计。

## 新增接口

```text
GET  /api/boss/execution/status
POST /api/boss/summons/{id}/execute-next
GET  /api/boss/summons/{id}/executions
```

OpenAPI 操作数量从 348 增加到 351。
