# PalPanel 自定义版 0.8.41

发布日期：2026-07-30

## 诊断与支持包

- 诊断页面新增一键体检，检查数据目录、服务目录、日志目录、备份目录、数据库和服务器状态。
- 新增脱敏支持包的生成、列表、下载和删除 API。
- 支持包固定收集构建、运行时、服务器状态、前置条件、主机能力、近期任务、审计和事件摘要。
- 可选附带最近 3 个日志尾部；每个最多 128 KiB，总计最多 384 KiB。
- 原始存档、数据库、环境变量和任意用户路径不进入 ZIP。
- 密码、Token、Cookie、API Key、绝对路径、IP、GUID、SteamID 和长标识在写入前脱敏。
- 默认最多保留 5 份、14 天，单包上限 50 MiB。

## 安全边界

- 所有接口要求交互式管理员会话，API Key 不可调用。
- 存储目录权限为 `0700`，ZIP 和元数据文件权限为 `0600`。
- ZIP 条目按名称排序并拒绝绝对路径、`..` 和 NUL。
- 日志只读取配置日志目录顶层的 `.log` / `.txt` 普通文件，不跟随符号链接。

## 发布流程修复

- 修复支持包工作流测试仍使用 API Key，和“仅交互式管理员会话可调用”的安全边界不一致而导致 Linux、Windows 打包同时失败的问题。
- 测试环境新增管理员会话凭据，支持包创建、列表、下载和删除继续通过完整路由与鉴权链路验证。
- GitHub 官方 Actions 升级到 Node.js 24 兼容主版本，避免 Node.js 20 弃用警告。
- 漏洞检查任务显式使用 `backend/go.sum` 和 `sav-cli/go.sum`，避免在仓库根目录查找不存在的 `go.sum`。

## 验证重点

- 支持包不得出现测试密码、Bearer Token、绝对路径、IP、GUID 或 SteamID。
- 删除或篡改元数据后，下载接口不得访问任意文件。
- 超过数量或保留期限的旧支持包应在新包成功生成后清理。
- Linux 和 Windows Release 均应能生成并下载有效 ZIP。

完整比较：`v1.3.0-custom.0.8.40...v1.3.0-custom.0.8.41`
