# 0.8.87 boss-registration2

本增量补齐固定坐标 Boss 的玩家报名入口、在线位置核验和面板管理界面。

## 游戏内报名命令

命令遵循积分系统的游戏命令前缀和“允许无前缀命令”设置：

```text
Boss列表
Boss报名 [场次编号或名称]
Boss签到 [场次编号或名称]
Boss报名状态 [场次编号或名称]
Boss取消 [场次编号或名称]
```

- 只有 `activity_kind=fixed_boss` 的等待或进行中召唤记录会进入报名候选。
- 多个场次同时开放时，玩家必须先发送 `Boss列表`，再带短场次编号报名。
- 报名幂等；重复发送不会重复占用名额。
- 取消报名立即释放名额。
- 关闭报名后，已经报名的玩家仍可查询状态或取消报名。

## 玩家位置核验

- 区域半径大于 0 时，报名和签到会通过 PalPanelBridge 查询玩家实时 `CachedPlayerLocation`。
- 默认读取 `Pal/Binaries/Win64/ue4ss/Mods/PalPanelBridge/config.ini`，也支持：
  - `PALPANEL_BRIDGE_URL`
  - `PALPANEL_BRIDGE_TOKEN`
  - `PALPANEL_BRIDGE_CONFIG`
- Bridge URL 必须为本机回环 HTTP 地址。
- 需要 PalPanelBridge 0.1.24 或更高版本。
- Bridge 暂不可用时仍允许先报名并占用名额，状态为“待核验”；玩家靠近活动中心后发送 `Boss签到`。
- 区域半径为 0 时不调用 Bridge，报名直接标记为无需区域核验。
- 批量刷新只更新当前在线且能安全匹配 PlayerUID、SteamID 或唯一昵称的参与者。

## 面板

新增 `/boss-registration` 页面及“Boss 报名”侧栏入口：

- 选择等待或进行中的固定 Boss 场次。
- 配置报名开关、人数上限、区域半径、Z 轴距离和活动开始后是否继续开放。
- 查看已报名、已到场、区域外和剩余名额。
- 管理员可添加参与者、重新读取单人位置、批量刷新在线位置或取消报名。
- 查看最近 200 条报名、区域核验和策略重算审计事件。

## 复用接口

未增加新的 HTTP 路由，继续使用：

```http
POST /api/boss/summons/{summon_id}/transition
```

新增控制状态：

```text
participant_register_online
participant_check_area_online
registration_refresh_online
```

现有 `registration_configure`、`registration_snapshot` 和 `participant_cancel` 保持兼容。

## 未包含

本增量不包含玩家传送、伤害归属统计和奖励自动结算。这些功能需要独立的安全执行及幂等账本。
