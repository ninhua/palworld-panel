# PalPanel patch 0.8.61

## 积分商城基础闭环

本版新增积分商城商品、兑换订单、库存与人工交付结算。

### 商品管理

- 商品名称、说明和积分价格。
- 有限库存或不限库存。
- 每名玩家累计限购。
- 上架、编辑和下架。
- 保留结构化 Payload，为后续 PalDefender 自动发物品、帕鲁模板和其他奖励类型预留。

### 兑换订单

- 根据 PlayerUID 创建兑换订单。
- 使用统一积分账本预扣积分。
- 占用商品库存。
- `PlayerUID + idempotency_key` 幂等去重。
- 重复请求不会重复扣款或重复减库存。
- 确认人工交付后提交积分预留。
- 取消待交付订单时自动退款并恢复库存。
- 已交付和已取消订单不可反向重复结算。

### 面板页面

新增 `/economy-shop`：

- 商品汇总和商品编辑。
- 管理员代玩家兑换。
- 按状态和 PlayerUID 筛选订单。
- 确认交付或取消退款。

侧边栏“积分系统”现在包含积分账户、任务系统和积分商城。

### API 与版本

新增 9 个 OpenAPI 操作，覆盖商品、订单和汇总接口。

以下版本均同步更新为 `0.8.61`：

- 后端运行时 `patchVersion`
- OpenAPI `PatchInfo.patch.version`
- 自动生成的 TypeScript API 合约

## 当前边界

本版交付方式仅为 `manual`。自动调用 PalDefender 发放物品或帕鲁模板将在后续版本接入；在自动交付上线前，管理员必须先在游戏内完成交付，再点击“确认交付”。
