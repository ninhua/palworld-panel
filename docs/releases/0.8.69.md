# Palworld Panel 0.8.69

## 诊断控制台可用性更新

- 诊断控制台在当前浏览器中保存最近 30 条成功执行记录。
- 可以从历史下拉框恢复请求、命令和响应结果。
- 支持删除单条记录或清空全部本地历史。
- 保存历史前会脱敏 Authorization、Cookie、Token、密码、API Key 等常见敏感字段。
- 新增“复制响应”“复制请求”和“复制完整记录”操作。
- 新增 PalPanel 回环、Palworld REST、PalDefender REST、端口、进程、资源和运行目录等诊断模板。
- Linux 与 Windows 自动显示对应的只读终端模板。
- 带凭据占位符的 HTTP 模板在替换前禁止执行，避免误发占位内容。
- 模板只填充诊断表单，不会自动执行。

## 数据与安全边界

诊断历史仅保存在当前浏览器的 `localStorage`，不会新增服务器端数据库表或 API。历史副本经过基础脱敏；当前实时响应的“复制响应”操作仍会复制屏幕上显示的原始内容，管理员应在对外发送前自行检查。

## 兼容性

本版不新增或删除运行时 API。OpenAPI 和生成的 TypeScript 合约仅同步补丁版本到 `0.8.69`。
