# 0.8.80

本版本修复 0.8.79 游戏事件桥接与在线任务采样造成的后端响应延迟。

## 玩家状态链路合并

- 在线时长任务不再从游戏事件桥接器调用 PalDefender `RESTPlayers`。
- 复用面板实时监控原有的 Palworld REST 玩家快照；该快照同时服务玩家在线状态、新玩家礼包和在线任务。
- 游戏日志中的昵称、PlayerUID 和 Steam/User ID 匹配优先使用实时监控共享快照；快照不可用时读取持久化玩家在线记录，不再发起第二次玩家目录请求。
- 在线任务最多每 30 秒结算一次，面板监控仍保持原有 15 秒采样节奏。

## 日志桥接性能

- 删除会追赶积压 Tick 的每秒 Ticker 循环，改为每轮扫描完成后再等待。
- 有新增日志时等待 1 秒；空闲时等待 3 秒。
- 每轮只检查最近两个 PalDefender 日志文件，不再重复遍历并查询所有历史日志游标。
- PalDefender 日志目录、日志开关和积分命令配置缓存 30 秒。
- 死信数量与游标统计只在管理接口请求时读取，不再放入后台高频扫描。
- 新增日志扫描耗时、读取字节数、共享玩家快照年龄和玩家采样耗时诊断。

## 兼容性

- 不改变签到、商城、任务、死信和事件幂等语义。
- 不新增或删除 API；OpenAPI 操作数量仍为 348。
- 补丁版本同步为 `0.8.80`。

- 积分页面桥接状态改为 10 秒刷新，观察记录和死信改为 15 秒刷新，减少管理页面持续打开时的数据库查询压力。
