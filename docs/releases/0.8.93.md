# Palworld Panel 0.8.93

## 存档差异降噪与 PalDefender 证据关联

- 默认事件明细只统计能够归属到玩家、据点或公会的物品和帕鲁变化。
- 排除野外宝箱、掉落容器、地图对象容器、未归属容器和纯世界所有者帕鲁产生的刷新噪声。
- 世界到玩家的帕鲁归属变化仍保留，并作为玩家新增帕鲁统计，避免误删真实捕获结果。
- 顶部汇总改为基于可信语义事件重新计算；容器属于底层诊断对象，不再计入默认业务汇总。
- 原始容器和字段变化仍保留在折叠的诊断明细与导出中，便于排查解析问题。
- 在两个存档快照时间范围内查询 PalDefender 事件，关联玩家登录、帕鲁捕获和开始制作日志。
- 捕获与登录日志匹配后标记为确认事件；开始制作日志仅作为关联证据，不直接宣称制作完成。
- 新增按时间范围查询游戏事件的数据库接口和索引。
- 优先解析 PalDefender/Unreal 日志前缀中的原始时间，无法解析时才使用读取时间。

## 兼容性

- 数据库结构保持兼容，时间索引通过幂等语句自动创建。
- API 响应结构保持兼容；现有前端会继续使用 `summary`、`event_total`、`events` 和 `details` 字段。
- 无 PalDefender、日志桥不可用或时间范围查询失败时，存档差异仍可正常返回，只是不附加日志证据。
