# PalPanel 0.8.49

## 世界地图运行时兼容性

- 将自托管地图运行时从刚发布且强制 WebGL2 的 MapLibre GL JS 6.0.0 回退到维护中的 5.24.0。
- MapLibre 5.24.0 会优先使用 WebGL2，并可在驱动或浏览器实现需要时使用 WebGL1；不再把手机和电脑上的统一构造异常错误归因为“无 WebGL”。
- 删除会创建临时 WebGL2 上下文并读取能力数组的前置探测，直接由地图运行时选择可用上下文。
- 浏览器运行时改为加载固定、自托管、带版本查询参数的 UMD bundle，避免旧的 6.0.0 ESM 文件被缓存继续执行。
- 纯 DOM 兼容瓦片模式仍作为最终兜底，但提示改为“MapLibre 回退”，不再误报 WebGL2 不可用。
- 离线镜像、许可证清单和同步器测试同步更新为 MapLibre GL JS 5.24.0。

版本：`0.8.49`


## 存档迁移后端重启恢复

- 主机角色迁移触发 PalPanel 服务重启时，反向代理可能短暂返回 HTTP 502/503/504；前端不再直接将其判定为迁移失败。
- 对迁移执行请求禁止自动重发，避免重复改写存档；页面会等待最多 60 秒，轮询存档接口直到后端恢复。
- 服务恢复后自动核对迁移存档是否存在，并明确区分“已确认完成”“后端恢复但结果未确认”和“后端未及时恢复”。
