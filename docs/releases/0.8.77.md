# 0.8.77

本版本补齐积分商城的玩家侧购买闭环。

## 新增

- 签名保护的玩家商城目录、购买和订单查询接口。
- 8 位商品兑换码，支持兑换码、完整商品 ID 或唯一商品名称购买。
- 游戏聊天命令：`商城`、`兑换`、`我的订单`，并支持 `商店`、`购买`、`订单` 别名。
- 商城命令遵循积分系统命令前缀与无前缀开关。
- 自动商品在聊天购买后立即尝试 PalDefender 交付。
- 游戏内私人回复显示余额、库存、限购、订单状态和交付结果。
- 商城管理页面展示兑换码与游戏命令提示。

## 安全与幂等

- 玩家侧 HTTP 接口复用现有游戏集成 HMAC 签名。
- 玩家订单查询固定按请求中的 PlayerUID 过滤。
- 游戏事件 ID 作为购买幂等来源，重复事件不会重复扣分或发货。
- `processing` 订单继续禁止自动重试，避免结果不确定时重复发放。

## 接口

新增：

- `POST /api/integrations/game/shop/catalog`
- `POST /api/integrations/game/shop/orders`
- `POST /api/integrations/game/shop/orders/query`

OpenAPI 操作数更新为 343。
