# PalPanel 自定义版 0.8.40

发布日期：2026-07-30

## 第三方镜像与离线构建

- 新增 `third_party/vendor-lock.json`，固定 PalOps Web、MapLibre、PalCalc、uesave、授权地图瓦片、完整 UE4SS SDK、GitHub Actions 快照和四类包缓存的镜像布局。
- 新增 `scripts/vendorctl.py`，支持初始化镜像、生成逐文件 SHA-256、验证、准备构建目录、输出 Linux/Windows 环境和安全清理。
- Linux 与 Windows 打包脚本新增 `online`、`mirror`、`offline` 三种依赖模式。
- 离线模式关闭 Go 代理，启用 Cargo/npm 离线开关，并要求 npm、Cargo、Go module 和 NuGet 缓存完整。
- 镜像中的 PalCalc 与 uesave 只在仓库缺失时临时准备，且仅删除带管理标记的目录。
- 已授权的 Palpagos 与 World Tree 瓦片可进入自有资产镜像，不再依赖原始地图仓库长期可用。

## 验证重点

- 修改镜像任意文件后，构建必须在 SHA-256 门禁阶段失败。
- 完全断网环境应能完成 Linux 与 Windows Release 构建。
- 镜像不得包含凭据、符号链接、设备文件或未经授权的第三方资源。
- 普通 `online` 构建行为保持兼容。

完整比较：`v1.3.0-custom.0.8.39...v1.3.0-custom.0.8.40`
