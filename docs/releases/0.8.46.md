# PalPanel 自定义版 0.8.46

## 地图资源发布附件接入

- 地图 POI、元数据和许可证继续从 `ninhua/palpanel-assets` 指定分支的不可变源码归档同步。
- 地图瓦片改为优先从该仓库 GitHub Release 归档附件下载，不再假设大体积瓦片存放在源码分支中。
- 默认读取最新 Release；支持 `PALPANEL_MAP_ASSETS_RELEASE_TAG` 指定标签。
- 支持 `PALPANEL_MAP_ASSETS_RELEASE_ASSET` 精确指定附件名。未指定时自动选择名称包含 `palpanel`、`palops`、`map`、`tile`、`poi` 或 `asset` 的 ZIP/TAR 归档。
- 私有仓库 Release 资产继续使用 `PALPANEL_MAP_ASSETS_TOKEN` 下载。
- 支持 ZIP、TAR、TAR.GZ 和 TGZ，安全检查路径穿越、链接、文件大小和总大小。
- Release 不可用但源码归档含完整瓦片时，自动回退源码归档。
- 构建生成的 `palpanel-map-assets.json` 记录实际 Release 标签和附件名称，便于追溯。

## 修复说明

此前同步器只下载 `palpanel-assets@main` 的 GitHub 源码 ZIP，因此只发布在 Releases 附件中的瓦片不会进入构建。本版本将源码数据与 Release 瓦片分开同步。

## 版本

- 后端、OpenAPI 和前端契约版本同步为 `0.8.46`。
- 新发布标签为 `v1.3.0-custom.0.8.46`。
