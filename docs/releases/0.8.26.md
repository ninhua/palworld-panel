# PalPanel 自定义版 0.8.26

本版本修复“实际 RCON 命令”检查被浏览器提前中断且没有操作审计记录的问题。

## 修复

- `/getrconcmds` 检查不再沿用前端 8 秒全局超时，改用 70 秒独立等待时间。
- 独立等待时间覆盖后端 30 秒首包等待，以及带斜杠和不带斜杠的兼容命令重试。
- 检查接口由只读 `GET` 调整为显式手动 `POST` 操作，成功和失败均进入现有操作审计。
- 检查仍只原样读取当前游戏进程暴露的 RCON 命令，不改变传送、删除物品等 GM 操作。

## 原因

`0.8.25` 已放宽后端 RCON 首包等待，但前端 API 客户端仍在 8 秒后取消请求，因此界面显示“当前面板后端响应超时”。同时，原检查接口使用 `GET`，会被只记录写操作的审计中间件按安全读取请求跳过。

## 验证

- 云端前端测试检查运行时命令检查使用 `POST` 和独立超时。
- 云端路由测试检查运行时命令检查作为受权限保护的操作接口注册。
- 云端完整 CI 编译并验证 Linux、Windows 安装包。
