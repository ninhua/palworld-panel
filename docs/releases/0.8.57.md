# PalPanel patch 0.8.57

## 修复

- 将 `0.8.53` 至 `0.8.56` 新增的积分系统、AstrBot 积分集成和游戏事件接口同步到 `docs/openapi.yaml`。
- 补齐 20 个运行时 API 操作的 `operationId`、权限标记、请求格式和响应定义。
- 为 AstrBot SQLite 迁移接口声明 `multipart/form-data` 的 `database` 上传字段。
- 为 AstrBot 与游戏事件入口声明 HMAC 集成权限和无浏览器会话认证模式。
- 将 OpenAPI 中的 PalPanel 补丁版本常量更新为 `0.8.57`。
- 将后端 `patchVersion` 更新为 `0.8.57`。

## 根因

Gin 路由已经由前几版覆盖包注册，但仓库的路由契约测试会把全部 `/api/*` 运行时路由与 `docs/openapi.yaml` 双向比较。新增路由没有同步写入规范文件，因此 `TestNewContractRoutes` 报告 20 个 `API route is missing from OpenAPI`。

## 验证重点

```bash
cd backend
go test ./internal/api -run '^TestNewContractRoutes$' -count=1
go test ./...
```

本版没有绕过或修改 `router_contract_test.go`。
