# PalPanel 0.8.48

## 世界地图分类筛选

- 将世界地图固定 POI 从只有一级大类的筛选，升级为“服务器数据 / 地点 / 敌人与首领 / 资源 / 收集品 / NPC / 帕鲁”分组下的二级小类筛选。
- 根据实际资源包中的 `category` 动态生成小类和数量，不把前端锁死在固定分类清单；未知小类也会以可读名称显示。
- 补充快速传送、地牢、地区名称、高塔、特殊地点、区域头目、高塔首领、敌人营地、遭遇目标、事件地点、矿物、宝箱、商人和帕鲁刷新点等中英日标签。
- 服务器动态图层拆分为公会据点、自定义标记、离线玩家、在线玩家和帕鲁实体，可单独显示或隐藏。
- 点击大类可批量显示/隐藏该组全部小类；点击小类只影响对应 POI。
- 标记详情现在显示“一级分类 / 小类”而不是内部分类 ID。
- 修正导入器将 `Dungeon` 错归为敌人类的问题，并识别敌人营地、遭遇、事件、原油和陨石等细分类型。

版本：`0.8.48`
