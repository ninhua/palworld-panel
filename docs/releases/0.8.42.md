# PalPanel 自定义版 0.8.42

发布日期：2026-07-30

## 修复问题

- 世界地图初始化显式设置 MapLibre 画布上限为 `4096 × 4096`，避免运行时默认值异常为 `null` 时在首次尺寸计算中读取数组索引并崩溃。
- 主机迁移允许 `LocalData.sav` 的 `SaveData.WorldMapMaskTexture` 及数字版本字段保留 UID-like 二进制碰撞，避免地图遮罩纹理被误判为未解析玩家 UID；其他未知二进制字段继续阻断。
- UID 重映射器统一将清单中的 `/` 路径转换为当前操作系统原生路径，修复 Linux 验证阶段读取 `Players\*.sav` 失败的问题。
- 修复 UID 重映射器 `concat!` 格式字符串使用隐式变量捕获而无法编译的问题。
- Windows 发布包构建、测试并包含 `palworld-uid-remap.exe`，同时校验服务端内嵌的 helper SHA-256。
- 修复 Windows 存档索引重试测试依赖快速同尺寸写入的文件时间戳变化而偶发失败的问题。
- OpenAPI TypeScript 生成器支持完整整数和浮点字面量，避免 `const: 1` 被生成为 `unknown`。
- 支持包工作流测试改用交互式管理员会话，保持 API Key 不可访问支持包的安全边界。
- 修正事件中心和配置修订历史中的 React Hook 依赖声明。

## 发布流程

- GitHub 官方 Actions 使用 Node.js 24 兼容主版本。
- Go 缓存显式指定 `backend/go.sum` 和 `sav-cli/go.sum`。
- Custom package release 在检测到标签或 Release 已存在时继续拒绝覆盖，并明确提示递增自定义版本和创建新发布说明。

## 行为与接口

- 后端补丁版本由 `0.8.41` 更新为 `0.8.42`。
- OpenAPI `PatchInfo.patch.version` 常量及前端生成契约同步为 `0.8.42`。
- 未新增环境变量，未改变数据库结构或公开 API 路径。

## 升级注意事项

- 必须重新构建并部署完整 Linux 或 Windows 包；仅替换前端静态文件不会更新 UID 重映射器。
- 部署后对世界地图页面执行一次强制刷新，避免浏览器继续使用旧 JavaScript 分块。
- 不要删除或覆盖 `v1.3.0-custom.0.8.41`；本版本使用新标签 `v1.3.0-custom.0.8.42`。

## 验证范围

- Linux、Windows 后端测试和发布包构建。
- UID 重映射器 Rust 测试及跨平台路径验证。
- Windows 发布包内容、helper 哈希和离线 E2E 校验。
- 前端 TypeScript、测试、Lint 与 OpenAPI 生成契约一致性。
