# 0.8.81 Boss 活动互斥维护增量 1

## 新增

- SQLite 持久化全局 Boss 活动锁。
- 自动与手动波次执行统一互斥。
- 多面板进程并发启动防护。
- 活动跨波次延迟和面板重启所有权保持。
- 已有活动状态的启动恢复。
- 暂停及不确定执行的安全阻断。
- 定时计划和显式计划键顺序保护。
- 锁取得与恢复审计。

## 释放规则

活动完成、失败、取消、删除，或者执行在进入活动状态前明确失败时释放锁。活动波次已经开始、执行结果不确定或等待人工对账时保留锁。

## 兼容性

本增量以 `boss-retry1` 为功能前提。失败波次通过 `retry_failed` 重新排队后，会在轮到该活动时重新取得活动锁。
