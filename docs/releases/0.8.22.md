# v1.3.0-custom.0.8.22

发布日期：2026-07-29（北京时间）

## 修复

- 面板自身的版本查询、`SHA256SUMS` 下载和 Linux 安装包下载现在会使用“系统设置 → 网络代理 → 安装与下载代理”。
- 支持通过现有的 HTTP、HTTPS、SOCKS5 或 SOCKS5H 安装代理访问 GitHub。
- GitHub API 和 Release 页面均不可达时，错误提示会明确指出代理配置位置以及 `HTTPS_PROXY` 环境变量方案。
- 系统设置中的代理说明已补充“面板自身更新”用途。

## 发布流程

- 自本版本起，打包工作流强制要求提交对应版本的中文更新日志。
- Release 将直接使用仓库中的中文日志，不再只生成空泛的提交比较链接。

## 验证

- 后端新增“面板更新使用托管安装代理”的回归测试。
- Linux、Windows、前端、Go、依赖漏洞及安装包检查由 GitHub Actions 完整执行。

## 升级说明

- 当前版本如果无法直连 GitHub，需要先临时设置 `HTTPS_PROXY` 并重启面板，或手工安装本版本。
- 升级到本版本后，可以直接在“系统设置 → 网络代理”中配置并启用“安装与下载代理”，后续面板更新会自动使用该代理。
- 本版本不包含配置格式破坏性变更。

**完整变更**：https://github.com/ninhua/palworld-panel/compare/v1.3.0-custom.0.8.21...v1.3.0-custom.0.8.22
