# 0.8.67

## Boss 多波次编排

- Boss 模板支持最多 20 个有序波次。
- 支持主 Boss、护卫怪和增援三种波次类型。
- 每波可独立配置 Pal ID、等级、数量、战斗倍率、生成半径、延迟和捕获规则。
- 模板无显式波次时自动兼容为一个隐式主 Boss 波次。

## 召唤波次快照

- 创建召唤记录时保存完整波次快照。
- 后续修改模板不会影响历史召唤。
- 支持等待执行、进行中、已完成、失败和已跳过状态。
- 前置波次未结束时禁止启动后续波次。
- 波次开始、全部完成或失败时自动同步召唤总状态。
- 每次逐波操作写入现有召唤审计事件。

## 面板

- Boss 模板卡片新增波次编辑器。
- 支持添加、删除、排序和从帕鲁目录直接选择。
- 召唤记录展开区域新增波次快照和中文状态操作。
- 汇总区域新增已配置波次数量。

## 兼容性

- 执行模式仍为 `record_only`，不会自动调用 PalDefender 或 RCON。
- 数据库启动时自动创建波次表；原有奖励、模板和召唤记录不迁移、不删除。
- 版本号已同步到后端、OpenAPI和生成的 TypeScript 合约。
