# PalPanel 自定义版 0.8.27

本版本修复 GitHub 不可达时，安全防护页面无法显示本地 PalDefender 状态和配置的问题。

## 修复

- 本地 PalDefender 状态与 GitHub Release 列表改为独立处理。
- GitHub 请求超时、限流或返回错误时，仍显示本地安装状态、版本、REST API、加载状态和 UE4SS 状态。
- 本地 `Config.json` 继续正常读取和编辑，不再受 GitHub Release 请求影响。
- GitHub 不可用时仅 Release 卡片显示“未获取到 Release”。
- 本地状态或配置自身读取失败时，显示对应的本地错误，不再与 GitHub 错误混淆。

## 原因

此前页面使用同一个 `Promise.all` 同时等待本地状态和 GitHub Release。任意一个请求失败都会中止整个加载流程，因此 GitHub 不可达时，即使本地状态已经成功返回，也不会写入页面。

## 验证

- 云端前端测试模拟 GitHub Release 请求失败，并检查本地版本与配置仍正常显示。
- 云端完整 CI 编译并验证 Linux、Windows 安装包。
