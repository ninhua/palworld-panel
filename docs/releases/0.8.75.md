# 0.8.75

诊断控制台响应显示增强版本。

## 响应 JSON 识别

- HTTP 响应体是有效 JSON 时自动切换为格式化显示。
- 忽略响应体开头的 UTF-8 BOM 和外围空白。
- 不依赖 `Content-Type`；即使接口返回错误的媒体类型，只要响应体是有效 JSON 仍可格式化。
- 空响应、截断后无法解析的 JSON 和普通文本继续按原始响应显示。

## 显示模式

有效 JSON 响应支持四种视图：

- 格式化 JSON：两空格缩进，默认视图。
- 压缩 JSON：单行输出，便于复制和比较。
- 树形查看：对象和数组节点可点击展开或折叠，并区分字符串、数字、布尔值和 null。
- 原始响应：保留服务端返回的原始文本。

响应状态、耗时和响应头始终保留。复制响应和复制完整记录会使用当前视图对应的文本；树形视图复制时使用格式化 JSON。

## 兼容性

- 没有新增或删除后端 API。
- 历史记录仍保存服务端原始响应；载入历史时重新识别 JSON，不会改写历史数据。
- 自定义诊断模板、请求头树形编辑和历史去重行为保持不变。
