# PalPanel 0.8.75

本版本重构诊断控制台的界面布局，不改变诊断接口或历史数据格式。

## 诊断工作区

- 将诊断类型、模板和历史记录合并到紧凑工具栏，减少重复卡片和大面积说明文字。
- 请求与响应使用稳定的双栏布局；窄屏自动改为上下排列。
- 请求构建器增加清晰的分区、请求摘要和固定执行区域。
- 响应区增加 HTTP 状态、耗时、截断状态和 JSON 类型摘要。
- 复制响应、请求、完整记录及清空结果收拢为统一工具栏。

## 请求头编辑器

- 默认显示全宽字段表格，不再在半宽请求面板内继续左右分栏。
- 字段模式和原始 JSON 模式改为页签切换。
- 常用请求头选择、添加按钮、字段计数位于同一工具栏。
- Authorization 的认证方式、Token 和实际发送提示保持可见且不挤压输入框。
- 删除操作改为独立图标按钮，空状态可直接添加首个字段。

## 兼容性

- 请求头 JSON、历史记录、自定义模板和响应 JSON 视图的数据结构均保持不变。
- OpenAPI 操作数量保持 338 个。
