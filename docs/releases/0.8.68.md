# 0.8.68

## Boss 定时计划

- 新增每日固定时间和五段 Cron 两种计划模式。
- 使用 IANA 时区计算下次运行时间，内置 Go 时区数据库。
- 后台工作器启动后自动扫描，之后每 30 秒检查一次到期计划。
- 到期计划自动创建 `record_only` 召唤记录和完整波次快照。
- 使用确定性请求键保证重复扫描不会重复创建召唤。
- 支持计划级坐标覆盖、启用状态和扩展 metadata。

## 提前预警与审计

- 支持 0 到 10080 分钟提前预警。
- 预警消息支持计划名称、Boss 名称和提前分钟数变量。
- 新增计划审计表，记录预警、召唤、失败和关联召唤 ID。
- 同一计划时间的预警和召唤事件均有唯一约束。
- 当前预警只写入审计，不会自动广播到游戏。

## 面板

- Boss 页面新增“定时计划”页签。
- 支持计划创建、编辑、归档、立即运行和手动到期扫描。
- 支持查看下次运行、上次运行和计划审计。
- 汇总区域新增启用计划数量。

## API 与兼容性

- 新增 7 个 Boss 计划接口，OpenAPI 操作总数更新为 333。
- 数据库启动时自动创建计划和计划审计表。
- 原有奖励、模板、波次和召唤数据不迁移、不删除。
- Boss 实际生成仍未接入 PalDefender/RCON，执行模式保持 `record_only`。
- 版本号已同步到后端、OpenAPI 和生成的 TypeScript 合约。

## 版本契约修复

- 修复后续覆盖包把运行时补丁版本从 `0.8.68` 错误回退到 `0.8.67` 的问题。
- 恢复运行时版本与现有 OpenAPI、生成 TypeScript 合约及发布说明的一致性。
- 保留上游兼容目标 `v1.3.1` 和已接入的存档迁移向导、PalPanelBridge 运行诊断。

## 中国时区默认值

- 普通计划任务在未填写时区时默认使用 `Asia/Shanghai`，不再回退到 `UTC`。
- Boss 定时计划继续使用 `Asia/Shanghai` 默认值。
- Linux systemd 主服务、存档索引器、PalCalc 侧车和更新器显式设置 `TZ=Asia/Shanghai`。
- 便携启动脚本在未由外部指定 `TZ` 时使用中国标准时间。
- 已明确填写其他 IANA 时区的现有计划保持原值，不会被强制改写。
