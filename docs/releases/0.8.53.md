# PalPanel 0.8.53

发布日期：2026-07-31

## 新增功能

- 新增以 `PlayerUID` 为主键的统一积分账户。
- 新增只追加积分账本，记录变动值、变动后余额、原因、业务引用、操作者和扩展元数据。
- 新增每日签到；以玩家与本地日期建立唯一约束，重复请求不会重复发放。
- 新增积分预留、确认扣款、释放退款和过期自动释放，为积分商店与交易订单提供事务基础。
- 新增游戏聊天命令执行接口，首批支持 `!签到`、`!积分`、`!帮助`，并按事件 ID 去重。
- 新增 AstrBot 签名接口，使后续 QQ 签到和积分查询可以迁移到 PalPanel 主账本。
- 新增积分汇总、账户查询、流水查询和管理员人工调整接口。

## 接口变更

新增受面板登录或 API Key 保护的接口：

- `GET /api/economy/summary`
- `GET /api/economy/accounts`
- `GET /api/economy/accounts/:player_uid`
- `GET /api/economy/accounts/:player_uid/ledger`
- `POST /api/economy/accounts/:player_uid/adjust`
- `POST /api/economy/accounts/:player_uid/checkin`
- `POST /api/economy/reservations`
- `POST /api/economy/reservations/:id/commit`
- `POST /api/economy/reservations/:id/release`
- `POST /api/economy/commands/execute`
- `POST /api/economy/maintenance/release-expired`

新增使用现有 AstrBot HMAC 签名鉴权的接口：

- `POST /api/integrations/astrbot/economy/checkin`
- `POST /api/integrations/astrbot/economy/balance`

## 配置

可选环境变量：

```env
PALPANEL_OPERATIONS_TIMEZONE=Asia/Shanghai
PALPANEL_DAILY_CHECKIN_POINTS=10
```

## 数据与兼容性

- 积分表直接建立在现有 `palpanel.db` 中，不创建第二个业务数据库。
- 新表使用 `economy_` 前缀，不修改旧表结构。
- 首次访问积分接口时自动建立表和索引。
- 余额具有非负约束；扣减余额不足时整个事务回滚。
- 相同业务引用和相同游戏事件重复提交时返回既有结果，不重复记账。
- 本版本没有自动迁移 AstrBot 插件原有积分；原积分迁移和插件切换将在后续增量包中完成。
