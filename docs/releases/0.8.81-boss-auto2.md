# 0.8.81 Boss 自动执行维护增量 2

## 完成内容

- 新增 `boss_runtime_leases` 持久化租约表。
- 自动波次工作器执行前必须取得数据库租约。
- 同一数据库的多个 PalPanel 进程不会同时推进 Boss 波次。
- 持有者可以续期自己的租约，其他持有者只能在租约过期后接管。
- 正常停止时按持有者释放租约，避免旧进程删除新进程租约。
- 租约时间统一使用固定宽度 UTC 纳秒格式，保证 SQLite 文本比较顺序正确。

## 安全规则

- 租约有效期为 30 秒。
- 每 2 秒尝试续期或接管。
- 单轮最多执行一个波次。
- `active` 波次、`running` 或 `uncertain` 执行记录仍会阻止自动推进。
- 本版本不自动重试失败或结果不确定的 RCON 命令。

## 尚未包含

- 管理端暂停、继续和跳过按钮。
- Boss 存活检测及自动判定上一波结束。
- 参与者、伤害归属和奖励结算。
