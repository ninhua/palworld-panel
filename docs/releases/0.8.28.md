# PalPanel 自定义版 0.8.28

## 修复

- 修复 PalDefender 已生成 RCON 回复，但面板因回复包使用通用 ID `0` 而忽略有效结果、最终显示超时的问题。
- `/getrconcmds` 现在兼容请求 ID 与 PalDefender 通用回复 ID，同时继续严格校验 RCON 执行回复类型。
- 调试日志新增被忽略回复包的 ID、类型和正文长度，便于排查其他 RCON 协议差异；不会记录密码或回复正文。

## 端口说明

- `17993` 是 PalDefender REST API 端口，不是 RCON 端口。
- `8212` 是 Palworld 官方 REST API 端口。
- 面板的 PalDefender RCON 命令读取 `PalWorldSettings.ini` 中的 `RCONPort`；未配置时才使用面板默认值 `25575`。
- 日志中的 `Running Palworld dedicated server on :12559` 是游戏服务监听端口。

## 验证重点

- 在安全防护页面执行“实际 RCON 命令”，应返回 `getrconcmds:0;...` 命令清单，不再等待至超时。
- 操作审计应记录本次检查及完整后端响应。
