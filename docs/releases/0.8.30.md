# PalPanel 自定义版 0.8.30

## 新增

- 新增独立“诊断控制台”页面，可从 PalPanel 后端测试回环地址和私网 HTTP/HTTPS 接口。
- 新增可选主机终端执行能力，通过 `PALPANEL_DIAGNOSTIC_SHELL_ENABLED=true` 显式启用。
- HTTP 与终端诊断统一限制为 15 秒和 64 KiB 输出，并纳入操作审计。
- 修复 UID 重映射器在 Linux 发布构建中错误使用 Windows 路径分隔符的问题。

## 安全

- 诊断接口仅接受已登录管理员的浏览器会话，不接受 API Key，也不允许在关闭登录验证时调用。
- HTTP 诊断拒绝公网、未指定、多播和链路本地目标，并对重定向后的目标重复执行私网校验。
- 终端执行默认关闭，每次执行均要求前端明确确认风险。

## 接口

- `GET /api/system/diagnostics`
- `POST /api/system/diagnostics/http`
- `POST /api/system/diagnostics/shell`
