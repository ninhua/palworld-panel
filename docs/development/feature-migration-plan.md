# PalPanel 功能移植计划

基线：`ninhua/palworld-panel` 的 `custom-stable` 分支。

PalPanelBridge 的独立优先级、完成标准和交付门禁见
[`palpanel-bridge-roadmap.md`](palpanel-bridge-roadmap.md)。

| 顺序 | 功能 | 状态 |
|---|---|---|
| 1 | 双模式面板更新与健康回滚 | 已完成 |
| 2 | 配置版本库 | 已完成 |
| 3 | 存档差异 | 已完成 |
| 4 | 崩溃守卫 | 代码完成，等待 GitHub CI 和实机验证 |
| 5 | 通知与事件中心 | 代码完成，等待 GitHub CI 和 Webhook 实机验证 |
| 6 | PalOps 世界地图替换 | 代码完成，等待 GitHub CI、地图资源同步和实机验证 |
| 7 | 第三方镜像与完全离线构建 | 代码完成，等待镜像初始化和断网构建验证 |
| 8 | 诊断与支持包 | 代码完成，等待 GitHub CI 和实机验证 |
| 9 | 多用户角色与高风险二次验证 | 未开始 |
| 10 | 统计、受控 RCON 和灾备 | 未开始 |
| 11 | 运维剧本和玩家治理 | 未开始 |

第 1 项包含：

- systemd 环境：外部 root 更新器切换完整 Release。
- 启动脚本环境：沿用原补丁的 `syscall.Exec` 原地热更新。
- 两种模式均校验官方 SHA-256、候选版本和启动健康状态。
- exec 模式只允许更新清单明确声明的“仅主程序”Release。

第 2 项包含：

- 每次成功应用配置时记录私密快照、父版本和修改字段。
- 历史差异对普通字段显示前后值，对密码字段仅显示配置状态。
- 恢复历史版本先生成草稿，再复用现有停服、启动、健康检查与失败恢复事务。
- 默认保留最近 50 个修订，过期私密文件进入可重试清理队列。

第 3 项包含：

- 每次成功索引记录脱敏压缩快照，相同指纹不重复。
- 快照按世界目录哈希隔离，切换存档源不会混合历史。
- 支持玩家、公会、基地、帕鲁、容器和全局物品数量变化。
- 每个世界默认保留 24 份、总体积限制 512 MiB，并校验快照 SHA-256。

第 4 项包含：

- 5 秒轮询运行状态，10 分钟内累计 3 次异常退出、OOM 或容器重启时熔断。
- Docker 模式先将 restart policy 改为 `no`，再停止崩溃循环容器。
- Windows 模式识别非 PalPanel 生命周期操作导致的进程退出。
- 熔断状态和最近 50 条事件持久化，PalPanel 重启后继续阻止启动。
- 管理员可在监控页打开诊断控制台，确认后仅解除熔断，或解除并启动服务器。

第 5 项包含：

- 监控告警、崩溃守卫和失败后台任务统一形成持久事件。
- 相同根因按稳定去重键累计次数，已解决事件再次发生时自动重新打开。
- 管理员可确认、解决或重新打开事件，全部状态变化写入时间线和审计。
- 可选 HTTPS/回环 Webhook 使用 HMAC-SHA256 签名和固定 Delivery ID，最多重试 6 次。
- Webhook 载荷不包含日志正文、文件路径、任务原始错误或签名密钥。


第 6 项包含：

- 地图前端使用固定、自托管的 MapLibre GL JS 5.24.0，并允许 WebGL2 / WebGL1 自动回退；不通过 CDN 加载运行时代码。

- 删除旧版 2048×2048 单图 SVG 投影，使用 PalOps Web 1.3.2 的 Palpagos / World Tree 双地图瓦片金字塔和仿射坐标。
- 固定 POI 使用 PalOps 1.2.0 数据基线：三种语言、30 类、1,251 条稳定记录；PalPanel 当前只暴露中文和英文界面。
- 玩家、据点、帕鲁和地图对象继续来自 PalPanel `/api/map/entities`，不迁移 PalOps 的 .NET 后端。
- 玩家刷新间隔支持 1/2/3/5/10/15/30 秒并保存在浏览器本地；探索状态同样只保存在当前浏览器。
- PalOps 元数据标记的不可再分发栅格瓦片不会默认进入源码或 Release；构建仅在管理员提供本地瓦片目录或显式确认权利后导入。

第 7 项包含：

- 使用统一锁定清单描述 PalOps、MapLibre、PalCalc、uesave、授权地图瓦片和包管理器缓存。
- 镜像初始化生成逐文件 SHA-256，构建前校验数量、大小与哈希。
- Linux/Windows 打包支持 `online`、`mirror` 和 `offline` 模式。
- 离线模式要求 npm、Cargo、Go module 和 NuGet 缓存完整，并关闭公共包源回退。
- 第三方镜像不得包含凭据、符号链接、特殊文件或未经授权的资源。

第 8 项包含：

- 在诊断页面执行固定白名单体检，显示数据目录、服务目录、日志目录、备份目录、数据库和服务器状态。
- 生成脱敏 ZIP，包含构建、运行时、主机能力、任务、审计、事件摘要和安全配置状态。
- 可选读取 `LogsDir` 顶层最近 3 个 `.log` / `.txt` 文件尾部，每个最多 128 KiB，总量最多 384 KiB。
- 不收集环境变量、数据库、原始存档或任意用户路径；密码、Token、路径、IP 和玩家标识执行双重脱敏。
- 支持生成、列出、下载和删除；默认最多保留 5 份、14 天、单包 50 MiB。

每项功能单独制作源码增量包。开始下一项前先同步最新 `custom-stable`。
