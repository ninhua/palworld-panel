# PalPanel v1.3.1

本次更新完善了存档迁移、实时地图和模组配置，并修复了 Palworld Dedicated Server 更新后的版本检测。发布包同时提供 Windows amd64、Linux amd64、源码和 `sav-cli` 源码包。

## 更新内容

- 游戏版本兼容规则改为 `1.x`，不再把支持范围写死在 `1.0.1` 或 `1.0.2`；后续 `1.0.3`、`1.1.x` 等 1.x 更新可继续被面板识别。
- 游戏更新判断以 Steam Build ID 为准。检测到新 Build 时，设置页会显示“更新游戏服务端”，并沿用备份、安全停服、SteamCMD 更新、Build 校验和重启流程。
- 新增旧玩家 SteamID/UID 自动迁移向导，并在发布包中附带 PlayerUID 迁移工具；修复 Linux 存档迁移的验证路径。
- 新增服务器存档、基地与实时地图视图，并补充安全清理流程。
- PalZones 模组配置增加专用编辑器，支持结构化编辑、初始化与保存校验。
- 补齐 v26 帕鲁目录及联动物品图标。

## 兼容说明

面板显示的 `1.x` 表示当前解析与管理能力面向 Palworld 1.x 系列。是否需要更新游戏服务端由本地和 Steam 的 Build ID 比较决定，因此不依赖固定的小版本号。

## 验证

本版本通过 Go 单元测试和静态检查、前端单元测试、类型检查、代码规范检查、生产构建、OpenAPI 契约一致性检查与源码敏感信息扫描。

安装和升级步骤见 [README.md](../README.md)。
